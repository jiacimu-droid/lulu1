# 露露机桌面小组件（2026-11-18 第一批真实源码）

## 当前接入范围

- **入口**：主桌面右上角「＋」；首屏问候区域、后续桌面空位长按；小组件选择器在当前桌面新建，在无法容纳时自动开新页。首屏既有问候、角色卡和应用不覆盖。
- **四个原生 Compose 组件**：每日星座运势、角色便签、倒计时、今日计划。2×1 / 2×2 / 4×2 三种尺寸；编辑弹窗可以选择尺寸、4 种原生艺术背景、导入本地 PNG/JPEG/WebP 背景、绑定现有角色、选择 12 星座、设置纪念日日期与标题、删除组件。
- **素材**：\`app/src/main/assets/widget_materials.webp.b64\` 是 4 幅原创插画的小型 WebP 图集（星夜/植物信纸/樱粉/复古像素），随 APK 离线打包；在 \`LuluDesktopWidgets.kt\` 内只解码一次并切成 4 张内存位图。自选背景复用受限的 \`LuluCssStore.importImage\`，存放于 App 私有目录。
- **持久化**：组件占位、页面、类型、尺寸、皮肤、绑定角色 ID、星座、文字、背景引用单独存储在 \`lulu_desktop_widgets_v1\`；与 \`lulu_desktop_layout\` 图标存档分离。无预装伴侣角色、无预生成虚假消息。只有配置真实角色时才显示名字。
- **拖拽与点击**：长按组件拖动后，对目标矩形校验页面边界、已有图标、其他组件；尺寸不适合时显示失败反馈而不是盖在其他控件上。编辑按钮在卡片右上角。星座卡在自身卡面显示绑定角色当天完整的模型原话；内容多时卡片内部可上下滚动，点击卡面不再打开解读弹窗，也不跳聊天页。便签/纪念日打开本地编辑，今日计划打开本地完整待办。
- **个人资料与星座**：读取现有「聊天 → 我的资料」里的生日（只解析月/日），新星座卡默认自动识别；组件仍可手动选星座或重新根据生日刷新。未向模型上传完整出生日期。
- **每日解读**：星座每日基础宜/忌是本地娱乐参考；绑定角色且启用解读后，由原角色聊天模型以 Full 人物上下文产生当天真实解读。相同角色+星座+日期的多张卡共享付费模型结果并保存在本机；失败不编造角色说话。
- **角色通知与刷新**：模型决定是否通知，用户必须同时开启组件通知及 Android 通知权限。按设备本地时间每天凌晨 00:00 排一次单次 WorkManager 任务（Doze、断网时可能延迟）；当天缺失结果且应用稍后启动会安排补齐，当天已有结果只安排次日 00:00。每张角色+星座+日期的结果共享缓存，失败至多进行两次间隔不短于一小时的工作重试；打开桌面只检查排程，不直接额外请求模型。当天每个角色+星座最多发一次通知。投递与私聊消息严格分开；没发出时不会宣称已经发送。
- **今日计划**：读 SelfTodoStore.readForRole 的真实待办，用 SelfTodoCalendar.allPending 过滤当天事项，卡片内直接勾选；点开可在弹窗查看并勾选今天全部事项。完成通过 completeFromWidget 按真实任务ID、完成日期和当前持久快照核验，提交后自序与桌面按 revision 更新。不能重复勾选、不能把未来事项伪装成今天，保存失败不谎报成功。
- **角色主动装修和留言**：通过既有 CapabilityRegistry + ToolRouter + 同人自主感知/私聊能力上下文，模型可自行选择 write_desktop_widget_note 或 decorate_desktop_widget。严格限制角色本人实际绑定的卡片，装修还需用户允许。可调整该卡背景/文字十六进制配色、圆角及本地皮肤；不会覆盖全局 CSS、素材或别的角色卡。真实便签正文与时间单独落盘并同步桌面。

- **CSS**：\`#Home .widget-horoscope\`、\`#Home .widget-note\`、\`#Home .widget-countdown\`、\`#Home .widget-planner\`，当前支持本地受控 CSS 的背景色、文字色、圆角及偏移；不是任意 Web CSS，也不会执行脚本。

## 2026-11-18 桌面真实尺寸与触控修复

主人的 Redmi 截图证明：旧桌面用窗口整页高度/4 给 4×4 网格每行分配高度，导致 4×2 近乎方形，2×2 竖长，2×1 也不够扁；组件底边又贴近下一行图标。实际源码现把第二页起统一使用 `min(可用高度/4, 可用宽度/4 × 1.04)` 为每行高度，图标、组件画布、拖动触点、拖影用相同规则，不改 4×4 的存档索引。第一面原有问候/角色信息仍保持原布局，不侵占。组件四边实际有 6dp 左右、10dp 上下内留白；下面图标再向下留 13dp 头部空间。2×1 从正方形恢复横向、2×2 接近方形、4×2 横向大卡；没有调整或清除用户已有的组件位置、皮肤、绑定角色与图标。

回归 `LuluDesktopWidgetTest.desktopGridSizesUseWidthNotEntirePortraitHeight` 比较高屏典型视口下三种卡片比例与横屏约束。需要新版同 SHA 的 APK/JVM 成功记录以及 Redmi 真机实际截图才能确认视觉与触摸；不能仅凭源码提交报已验收。

## 2026-11-18 每日零点自动解读

已将原来按启动时间漂移的 24h 周期请求换为以设备本地日期和凌晨 00:00 为锚点的单次 WorkManager 自续排程；卡片启用并绑定真实角色后自动注册，卸载/禁用全部星座卡时撤销计划。相同角色与星座当天仅用一次真实模型结果，不产生预设假台词；联网与 Android 后台限制可能令任务延后，不能保证精确在 00:00 发出。恢复运行后如当天尚未完成，会补执行；重试次数受限。已移除打开桌面时直接调用模型；角色解读自动写入桌面卡片，已撤销不必要的解读弹窗及其手动入口。不截取屏幕，不更改人物自主感知频率与身份。回归 `LuluWidgetLiveIntegrationTest.dailyMidnightScheduleUsesFirstInstantOfEveryLocalDay` 验证本地日期锚点及晚启动补执行决策；实际 Android 构建、后台 Doze/断网与多角色真机日跨仍须对应主干 CI 与实机确认。

**2026-11-18 定时点修改**：主人明确改为按设备当前本地日期的零点（00:00）触发，即新一天刚开始就具备执行资格；原 08:00 排程在新版本启动并同步排程时取消，以免同时执行旧定时任务。实际运行仍受 Android WorkManager 省电、网络约束影响，无法保证零点第一秒就发起真实 HTTP 请求；若延迟，在本日仍有未成功解读时补齐。绑定角色、模型 Full 输入、当天成功缓存和通知权限均不变。新增跨日 23:59:59 → 00:00:00 以及设备时区边界测试。此变更的 CI 与真机仍待单独验证。
