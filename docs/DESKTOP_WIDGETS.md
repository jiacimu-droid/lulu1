# 露露机桌面小组件（2026-11-18 第一批真实源码）

## 当前接入范围

- **入口**：主桌面右上角「＋」；首屏问候区域、后续桌面空位长按；小组件选择器在当前桌面新建，在无法容纳时自动开新页。首屏既有问候、角色卡和应用不覆盖。
- **四个原生 Compose 组件**：每日星座运势、角色便签、倒计时、今日计划。2×1 / 2×2 / 4×2 三种尺寸；编辑弹窗可以选择尺寸、4 种原生艺术背景、导入本地 PNG/JPEG/WebP 背景、绑定现有角色、选择 12 星座、设置纪念日日期与标题、删除组件。
- **素材**：\`app/src/main/assets/widget_materials.webp.b64\` 是 4 幅原创插画的小型 WebP 图集（星夜/植物信纸/樱粉/复古像素），随 APK 离线打包；在 \`LuluDesktopWidgets.kt\` 内只解码一次并切成 4 张内存位图。自选背景复用受限的 \`LuluCssStore.importImage\`，存放于 App 私有目录。
- **持久化**：组件占位、页面、类型、尺寸、皮肤、绑定角色 ID、星座、文字、背景引用单独存储在 \`lulu_desktop_widgets_v1\`；与 \`lulu_desktop_layout\` 图标存档分离。无预装伴侣角色、无预生成虚假消息。只有配置真实角色时才显示名字。
- **拖拽**：长按组件拖动后，对目标矩形校验页面边界、已有图标、其他组件；尺寸不适合时显示失败反馈而不是盖在其他控件上。编辑按钮在卡片右上角；点击角色相关卡片可进入已有角色会话（无会话时打开编辑），今日计划进入自序。
- **个人资料与星座**：读取现有「聊天 → 我的资料」里的生日（只解析月/日），新星座卡默认自动识别；组件仍可手动选星座或重新根据生日刷新。未向模型上传完整出生日期。
- **每日解读**：星座每日基础宜/忌是本地娱乐参考；绑定角色且启用解读后，由原角色聊天模型以 Full 人物上下文产生当天真实解读。相同角色+星座+日期的多张卡共享付费模型结果并保存在本机；失败不编造角色说话。
- **角色通知与刷新**：模型决定是否通知，用户必须同时开启组件通知及 Android 通知权限。Worker 每24小时请求一次后台刷新（可能被系统延迟），应用打开/跨午夜也检查缓存，同一角色+星座+日期最多发一次通知。投递与私聊消息严格分开；没发出时不会宣称已经发送。
- **今日计划**：读 SelfTodoStore.readForRole 的真实待办，用 SelfTodoCalendar.allPending 过滤当天事项，卡片内直接勾选；点开可在弹窗查看并勾选今天全部事项。完成通过 completeFromWidget 按真实任务ID、完成日期和当前持久快照核验，提交后自序与桌面按 revision 更新。不能重复勾选、不能把未来事项伪装成今天，保存失败不谎报成功。
- **角色主动装修和留言**：通过既有 CapabilityRegistry + ToolRouter + 同人自主感知/私聊能力上下文，模型可自行选择 write_desktop_widget_note 或 decorate_desktop_widget。严格限制角色本人实际绑定的卡片，装修还需用户允许。可调整该卡背景/文字十六进制配色、圆角及本地皮肤；不会覆盖全局 CSS、素材或别的角色卡。真实便签正文与时间单独落盘并同步桌面。

- **CSS**：\`#Home .widget-horoscope\`、\`#Home .widget-note\`、\`#Home .widget-countdown\`、\`#Home .widget-planner\`，当前支持本地受控 CSS 的背景色、文字色、圆角及偏移；不是任意 Web CSS，也不会执行脚本。

## 明确尚未完成，不能报已验通

- 本轮未取得对应提交的 Android APK/JVM CI 最终成功证据；也未取得 Redmi 真机布局、长按拖动、输入法、字体放大、旧布局升级、多页面组合和屏幕旋转截图。已补 \`LuluDesktopWidgetTest.kt\` 纯逻辑测试，仍需真实 CI 跑通。
- **已接通但待验证**：每日模型解读有独立的按天 Full 调用，与既有主动感知共用同一身份和记忆，却不是同一轮付费模型请求；不应声称这是角色五分钟自主生活的免费延伸。角色主动便签/装修则是已有角色工具链的可选动作，不强迫角色一定执行。通知需在真实 Android 后台调度和权限下实测。
- **待办已接通但待验证**：真机需要检验触摸/滚动/长按并发、自序在后台的读写刷新、旧数据迁移以及拒写时原记录不受损。
- 尚未接入第三方星座/天气 API，也没有 Android 系统主屏幕的 \`AppWidgetProvider\`；这些是露露机 App 内桌面组件。
- 现有个人资料生日已经复用来识别星座；未引入外部个人资料账号，也不收集出生时刻或城市用于星盘推演。
- 尚未完成全局任意像素所见即所得布局、组件移动到第一页现有固定卡片之间、素材包分享导入、不同组件单独 CSS 实例选择器。无素材版权外链；原创美术经过压缩离线入库。

## 回归用例

\`LuluDesktopWidgetTest\` 覆盖单日固定运势、组件不覆盖图标、空位冲突拒绝、满页自动找下一页、首屏不放置以及组件彼此不重叠。真机需检验 2×1 的内容缩排与 2×2、4×2 的背景图裁剪、点击/长按竞争、支持已有 CSS 主题、进程重启保留每张卡的配置。
