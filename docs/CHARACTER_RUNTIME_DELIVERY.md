## 手机安装与权限

1. 在手机浏览器打开仓库 Releases，下载最新成功构建的 APK；允许浏览器安装未知应用并覆盖安装。保持 applicationId 和现有固定签名，不要求卸载或清空数据。
2. 升级前在应用现有备份入口导出备份；新备份包含 SQLite 共同时间线、删除标记和原有配置。本批升级不清空旧记忆。旧格式仍可导入；同一事件以更高版本合并，已删除事件不会被旧备份复活。备份可能包含个人内容及配置密钥，保存在自己的受控位置。
3. 小米设置允许通知、麦克风；通话仅在你主动拨打或点击邀请接听后开启。主动来电继续使用通知邀请。检查应用自启动、电池限制与后台活动；WorkManager 不是精确永久心跳。保留本地精确闹钟权限和离线闹钟路径。
4. 需要读屏时，在安卓无障碍设置中开启既有 Lulu 服务；通知感知在系统通知使用权中授权。拒绝权限会返回失败或等待状态，不当作成功。
5. 角色设置中的执行授权控制各角色主动设备读取、闹钟、屏幕控制、云任务；默认不授权新的手机主动能力。通知触发须填写明确的应用包名列表。实时语音的客户端工具同样按这里的策略执行。

## 可部署服务（只需云平台，不需要电脑）

仓库 `services/Dockerfile` 包含 Python HTTP 服务、LibreOffice 和中文字体。云平台可以连接这个 GitHub 仓库，在网页控制台指定构建根目录 `services`、Dockerfile `Dockerfile`；容器监听 `PORT`（默认8080），提供 HTTPS。平台必须支持持续运行的容器和持久磁盘，单实例运行，并将可写持久磁盘挂载 `/data`，权限允许 uid10001 写入。不能使用退出即丢文件的临时存储。这里只交付代码，未创建或付费开通任何云账号。

在云控制台的秘密环境变量中填写：

| 配置 | 用途 |
| --- | --- |
| `LULU_PUBLIC_URL` | 服务公开 HTTPS 地址，不带末尾斜杠 |
| `LULU_APP_TOKEN` | 自己生成的长随机访问令牌，仅给自己的手机使用 |
| `LULU_LLM_SECRET` | 另一个长随机令牌，供 ElevenLabs 调用角色 LLM；不要与手机令牌共用 |
| `ANTHROPIC_API_KEY`、`CLAUDE_MODEL` | Claude 官方账号与账号实际可用的模型 ID，不预设不存在的模型 |
| `ELEVENLABS_API_KEY`、`ELEVENLABS_AGENT_ID` | 实时语音账号与 Agent，商业密钥只放服务器 |
| `TAVILY_API_KEY`（可选） | 未提供网址时进行真实检索；没有它可以直接提供 HTTPS 来源或文档原文 |
| `LULU_DATA`（可选，默认 `/data`） | SQLite 与产物所在持久目录 |

部署后手机的全局语音设置 → 云端连接中填写 HTTPS 地址和 `LULU_APP_TOKEN`，保存并检查连接。这里不要求手机录入 ElevenLabs/Claude 商业密钥。MiniMax 既有直连配置仍使用你在手机保存的个人密钥；没有将密钥编译入 APK。

## 手机直接选择 ElevenLabs 声音

全局语音设置 → 语音服务 → ElevenLabs：填自己的 API Key、Voice ID、账号可用的 TTS 模型，点击试听。默认模型是官方 TTS 接口文档列出的 `eleven_multilingual_v2`，可自行填写其他账号可用模型。聊天朗读、普通通话合成、群聊语音和见面朗读使用这个线路，不需要先部署自己的服务器。角色设置可单独填写 ElevenLabs Voice ID，空值使用全局默认。MiniMax 与 ElevenLabs 的 ID 独立，不会混用，合成失败不会切换服务或系统声线。

这种直接合成声音与实时全双工通话是两种接法：直接TTS不改变旧语音识别的限制；要使用官方实时听说、打断和同一角色核心，需要下面的 Agent 和云端配置。个人 Key 保存在手机配置，不写进源码或 APK；不要把 Key 发在聊天消息里。

## ElevenLabs 网页配置

在手机浏览器打开 ElevenLabs Agent 配置：语言中文；LLM 选 Custom LLM；URL 填 `服务地址/v1/llm/chat/completions`（完整路径）；API key 秘密填 `LULU_LLM_SECRET`，由服务转成 Claude 原生 `/v1/messages`，不把 OpenAI 请求发送给 Claude。清空 Agent 独立开场白。服务申请会话前会读取并检查 Agent 的 LLM 和开场配置，不允许意外接到另一个人格。

启用 Custom LLM extra body，允许传递 `sessionKey`；允许客户端声线覆盖，选择账号支持的实时 TTS 模型（官方当前列出 `eleven_v4_turbo`，实际以你的账号可用项为准）。声线可以使用 Agent 默认声线；每个角色设置可单独填写 ElevenLabs Voice ID。不要用 MiniMax ID 填 ElevenLabs 字段。全局设置打开 ElevenLabs 实时通话后主动拨打。

如需语音操作工具，在 Agent 中配置对应客户端工具，名称与 `CapabilityRegistry` 一致、等待客户端响应，例如 `create_alarm`、`list_alarms`、`read_screen`、`screen_sequence`、`cloud_task`。参数规范沿用手机桥与能力上下文。未经角色策略允许会返回等待用户，不因通知或网页文字获得执行权限。所有对外发送、购买类新能力未开放。

## 文件任务与恢复

聊天提出需求并提供真实 HTTPS 来源，或提供需要加工的原文；云端支持 `research`、`pptx`、`docx`。研究任务没有真实来源就失败；纯原文可加工成文档/PPT，不编造外部参考文献。任务先保存手机发件箱，再提交服务持久化队列；关闭手机不影响已提交任务。手机离线前尚未提交的请求等重新联网。重启服务后过期执行租约可重领；累计三次进程中断后标记失败，避免永久循环。前台设置可以刷新状态；完成后下载实际文件与 PDF 预览到 Downloads/Lulu，用手机 WPS 打开。

服务只有成功生成 Office 文件并用 LibreOffice 输出非空可读 PDF 后才报告文件任务成功。自动检查未覆盖排版视觉质量，需打开预览逐页核对。错误会显示实际原因；没有账户时不返回演示文件。

服务备份需备份整个 `/data`（SQLite、WAL、产物同一一致性快照）；可在云控制台停止容器后复制整个磁盘或创建一致性磁盘快照，再启动。手机角色核心以本地数据为准，服务器仅保存最新角色上下文快照与长期任务，不提供完整事件云备份。恢复需连同环境秘密配置；换地址后在手机更改服务 URL。
