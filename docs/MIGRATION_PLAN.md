# Lulu1 独立迁移计划

## 工作边界

- 来源仓库：`jiacimu-droid/lulu`，只读取现有 `master`。
- 目标仓库：`jiacimu-droid/lulu1`，只修改现有 `main`。
- 不新建分支。
- 不创建一次性或额外工作流。
- 允许迁入主人明确拥有的现有正式构建发布工作流和代码索引工作流，但迁入前必须核查路径、触发条件和权限。
- 不整仓复制，不继承旧 Git 历史。
- 未确认来源或不属于本项目的页面与资源不得直接迁入。

## 已确定视觉方向

全项目采用 `docs/DESIGN_SYSTEM.md` 中的 **方案 B · 暖纸极简**。

核心特征：暖白纸感、浅麦黄色主强调、低饱和蓝灰线条、轻边框、低阴影、少渐变和充分留白。

## 完成定义

一个模块只有同时满足以下条件才算完成：

1. 来源和归属明确；
2. 功能与数据依赖完整；
3. 遵守暖纸极简设计系统；
4. 无旧品牌和旧页面视觉残留；
5. 可通过构建；
6. 真机主要流程可用；
7. 已记录迁移说明和剩余问题。
