# 方块小岛 × 迷雾摸金：玩家心理与可玩性设计规范

> 2026-11-07 制定。**本文件是玩法体验规范，不是第二份待办看板**。唯一任务/完成状态以 [LULU_EXPERIENCE_ROADMAP.md](LULU_EXPERIENCE_ROADMAP.md) 的 G-02/G-03 为准。以下“设计目标”不代表 APK 已实现；必须以最新 main 源码、测试、真实 APK 为准。

## 大厅单屏交互红线（2026-11-12 主人确认）

方块小岛、迷雾摸金的**主游戏大厅只能是一整屏**，横屏与竖屏均不得把主容器做成 `verticalScroll` / `LazyColumn` 的纵向长页面。场景与人物是视觉主体；玩家席位、邀请入口、关键状态、开始/继续按钮必须直接可见。装备/难度/委托、商店/珍藏、任务详情、可邀请列表改由用户点击后打开独立弹层或二级界面；**仅这些局部详情允许滚动**。不可简单关闭滚动而将下方入口裁切掉。窄横屏、矮屏及放大字体需要缩小角色卡与间距、确保核心按钮不越界；真机验收须分别测试游戏初始/有存档/邀请中/已接队友、360dp 与 412dp、横竖屏及放大字体。此规则独立于局内地图的拖动、摇杆和局内独立日志滚动，不得误删真正的游戏操作。

## 一、共同原则：玩家为什么自愿回来

不是让 UI 要求玩家“每天打卡”，也不是只靠极低概率让人刷。可持续乐趣由五种不同体验组成：

1. **立刻有手感**：移动、采集、攻击、开箱必须在手指按下时清晰回应；音画反馈与实际规则结果一致，不出现假入包、假攻击或等待模型才移动。
2. **今天有明确选择**：玩家自己选择探索、建造、养宠、打怪、收藏；不存在唯一指定的“正确”行为或强迫连胜/签到。
3. **努力真的改变世界**：房屋留存、宠物陪伴、图鉴解锁、材料消耗和撤离收益都落同一真实存档；重进仍能看到自己留下的痕迹。
4. **惊喜有来源**：稀有物品/特殊生物/意外事件需要规则、条件、可追溯来源；故事演出不能替代实体和回执。
5. **长期目标可完成**：可以有少量特别罕见的追求，但不能用“不透明极低概率+重复打卡”强迫玩家投入；必要时开放可累积的替代兑换路线，避免全收集无法完结。

**成本原则**：地形、动物、怪物、掉落和存档在本地规则运作。AI 角色在已有模型决策时读真实现场、选择既有可执行动作并收到回执；不按每次游戏移动额外付费调用。

## 二、方块小岛：我拥有的世界

### 2.1 玩家幻想与定位

**最终体验定位：生存 × 冒险 × 自由建造的双人岛屿生活。** 玩家与真正自主的角色流落小岛：白天准备食物、材料和工具，夜里需要庇护，出门冒险发现新生态、新蓝图与好看的装饰材料；带回家建设能真正休息、制作、储藏、防御的房屋与营地。玩家希望看到“这棵树是我种的，那间屋子是我建的，那只动物是我救回来养的”。生存是轻压力、可改善的需求，绝不只是反复吃饭掉数值；冒险提供差异化地点和值得带回的东西；建造是永久改变世界的兑现。可选和平建设，不用强制打首领才配拥有漂亮家园。角色基于本人意愿、真实物理条件与关系自主领路/保护/采集/施工，不写死「角色必帮」或偷偷增加动作。

### 2.2 三层游戏循环

| 时间感受 | 玩家行为 | 游戏必须给到的反馈 |
|---|---|---|
| 每 10–30 秒 | 连续行走、发现异样、砍一棵树、钓鱼、撸宠物 | 清晰命中、音效、材质/粒子、真实材料变化 |
| 每 5–15 分钟 | 扩建一间房、完成一件家具、结识一个物种、探完一处角落 | 游戏世界肉眼可见变化、解锁配方/地图发现、家园成果 |
| 跨日/长期 | 家园区域、不同栖息地、物种变体、稀有蓝图、首领与特殊装备 | 长期地图/图鉴、可选择目标、带来源的成就记录 |

### 2.3 建议的完整成长路线（按体验而非固定时钟触发）

- **初期：安家**。采木石→工作台→斧镐剑→篝火床铺→抵御第一批危险；既有五阶段引导。
- **探索：地图开始“有故事”**。不同可达地带有实际特殊地貌、物资、动物、藏宝物和机制。首次发现出现短动效与永久发现记录，而非重复生成“你发现了树”。
- **生活：生态照料**。寻找兔/鸭/狐等可见生物，先接近观察，再用合适食物结识；带回家，动物会缓慢靠近，经过真实回合可互动并产出小礼物。未来增加稀有外观、栖息环境、围栏、饲育和生长，不把现有三只宠物称作完整生态。
- **创造：从“铺墙”变成“我的房子”**。屋顶与室内地板、门窗、灯具、床、农田、围栏、家具、展示柜、房屋设计保存/复制（必须扣资源）；家园可无战斗地持续装饰。
- **冒险：解决更难的问题**。探索森林深处/洞穴/遗迹，获得稀有矿和附魔材料；装备升级有明确材质视觉差异与实战用途；首领有蓄力、走位和阶段行为，奖励是专属物品而非仅几个金币。
- **收藏：能摆出来看**。动物图鉴、地形与事件图鉴、装备与家具、首领战利品不共用一条百分比；每个物件有发现条件、来源记录及陈列位置。

### 2.4 地图与画面规范

- 现有 28×22 地图太小。正式扩容建议保留**旧岛起点/建筑与坐标**，在边缘引出可分页载入的地区；按种子决定地形与发现对象，不能每次打开重抽已经确认的奖励。
- 高密度场景要有正确层级：土地/沙岸→草叶花石→房墙家具→人物动物→前景树冠→夜间局部灯光/粒子。人物不能永远被 HUD 遮住。
- **2026-11-11 主人已批准的正式审美方向：清新、简约、柔和、漂亮的岛屿。** 参考柔和手绘/精致低多边形审美的色彩与体块，不等于把现有 2D 游戏粗暴换成 3D 引擎。要有通透的海水、舒适的绿地、小而精致的木屋、轻柔天光；自然景观要留白、色系统一、主体清楚。禁止用密密麻麻的杂物、过饱和荧光和厚重黑色 UI 遮罩假装高品质；先做一块能看出“生活痕迹”的高质量样板地带，确认真机 FPS 再扩图。旧像素贴图或复杂背景与该审美冲突时，以本条最新确认方向为准。
- 操作保留持续方向键、自动采集触手可及的资源、轻触选择/长按选目标。场景占主要屏幕，HUD 只保留当前最重要的生命、快捷动作和短期目标，制作/图鉴放可收起菜单。

### 2.5 人物共同游玩

同行角色必须看到真实资源/怪物/小动物/房屋，自己选择采集、保护、协作建造、照料动物或邀请探索；可以发表本人看法，但不允许脚本自动给所有角色统一偏好。每个可执行结果记录本人的动作/回执，不把看见玩家做成“角色自己做了”。

## 三、迷雾摸金：寻获真正美丽、独特、值得炫耀和使用的奇珍异宝

### 3.1 玩家幻想与定位

**第一核心是宝物之美与占有的快乐，不是撤离风险。** 玩家摸到一件珍宝时，必须先感到“这件东西真的好漂亮、好特别，我想拥有它”；其次能细看每处设计、在自己的藏宝馆或家园摆出来、把真实珍藏分享给别人；部分稀有宝物还应有能真的触发的生活、探索或互动效用。**稀有但丑、只有数值和名称的物件不算精品奖励。** 地牢、怪物、限时撤离、负重与风险抉择都是为寻宝服务的配角，而不是主玩法。珍宝须有独立的高品质造型、可辨的材质与细节、可信出处和真实持久化展示；已经拥有才允许展示/分享，尚未实现的佩戴/能力绝不在 UI 中伪称可用。玩家可选择专注搜寻、收集套装、鉴赏、设计展示空间和寻找珍宝的真实用途。

### 3.2 三层游戏循环

| 时间感受 | 玩家行为 | 游戏必须给到的反馈 |
|---|---|---|
| 每 10–30 秒 | 开雾、发现怪影、躲避、格挡、开箱 | 看得见的预警、命中、箱体变化、实物入包/落地 |
| 每一局 | 发现漂亮宝箱→看见独特珍宝→真实入包→带回鉴赏或展示 | 独立外观和材质、真正的开箱惊喜、带得回的实体与可交互鉴赏 |
| 长期 | 收藏珍宝套系、陈列炫耀、追求漂亮孤品、解锁部分实用效用 | 可永久观赏的藏宝馆、真实展品/分享、少量确实生效的能力和新展厅 |

### 3.2.1 美丽宝物优先的品质验收

- **视觉门槛**：至少先做一小组真正可在手机上放大鉴赏的高精度原创珍宝美术（例如月银胸针、星穹冠冕、冰魄竖琴）；每件造型/材质/局部细节必须一眼不同，不能只是同个圆形图标换颜色。
- **拥有的满足**：开箱、入包、实际撤离、收藏展出使用同一件实体。鉴赏可主动打开、自由查看，不强制连播；展示和分享必须引用真实拥有的宝物，出售立即撤展。社交可通过系统分享，不擅自替玩家发朋友圈。
- **用处有选择**：漂亮是基本条件，某些精选宝物可提供灯光/音乐/特殊表情/陈列家具/探索便利等真正有用、真正可执行的效果；其余纯艺术品仍有收藏价值，不为了数值强行加技能。
- **稀有度不等于审美**：普通级也可以好看，稀有级要有独特设计与故事，顶级宝物必须有令人眼前一亮的美术与纪念性。测试时让玩家不知道标价，仅看图选“最想带走”的宝物。
- **真实开发状态**：现有物件目录、通用矢量外形和本轮展示卡是第一阶段，不代表高精度美术和实用效果已经上线。与其每局多塞十种廉价奖励，不如认真制作几件让玩家心动的收藏。

### 3.3 关卡与风险层次

- **出发前**：只展示三个关键选项——同行伙伴、主要装备、携带药剂。仓库里珍惜的物品可以展示但不被冒险自动带走。
- **进入遗迹**：至少两种路径取舍：安全路上普通箱更密集；危险路线有稀有箱/隐藏祭坛但守卫更强。玩家有探索时长压力，却不靠不可见强制倒计时坑掉物品。
- **开箱前**：普通箱直接开；稀有箱可选稳妥拿稀有物，或消耗工具破封成珍贵箱并面对一只实际生成的守卫。这是**玩家自主做出的风险交换**，不能只是弹一行“有敌人”。
- **背包决策**：负重不够时宝物真实掉地，玩家可丢低价值物、请同伴帮忙搬、或放弃。出门时没有收到的实物不能算图鉴解锁。
- **撤离**：让玩家知道回出口的方向、可能遭遇的敌人和倒计时。失败保留公平记录，但丢失本局未撤出的实物；不对已经成功入库的物品造成隐形损失。
- **准备下一局**：获得的新藏品/装备是继续探索的线索；重复宝物的出售收益能换补给或配方，不要让铜币只有两个用途。

### 3.4 珍宝收藏的满足感

- 稀有度**可辨认**：普通有朴素材质，稀有是蓝银冷光，珍贵是暖金圣光，秘宝有特殊音效、光柱、名字卡和一次性鉴赏演出。
- 出货链条依次是：**实际开箱成功 → 唯一确定的物品生成 → 放入背包或真实掉地 → 玩家撤离成功 → 入库 → 永久图鉴**。各阶段必须在存档和 UI 上对应，不允许动效抢跑。
- 已实装的基础：28种目录物件（含祭坛封印之心及极低概率晨星之核）、成功撤离收录图鉴、可卖实物保留收藏名、稀有宝箱可额外破封。目录仍只是第一版；还需检查全部条目的实际可达性和难度分布。
- 罕见物不能替代可见成长：普通局也应能推进蓝图、地图知识或资源储备。收藏可慢，但必须有新的“我正在靠近目标”的证据。

### 3.5 画面与情绪节拍

- **2026-11-11 主人已批准的正式审美方向：清冷、简约、神秘、精致的珠宝展厅。** 游戏画面不靠铺满图腾、金边和光柱取胜。环境是克制的深石灰/蓝黑/雾感，仅用一两处柔和定向光让真正美丽的珠宝成为视觉中心；平静背景、细小金属细节、留白优先，取消多重霓虹外圈、金币数字轰炸和过度装饰。稀有度可以通过材质与造型表达，不能只给不同宝物套不同颜色的同一种图标。
- **进入**：营地的柔暖色→遗迹冷石灰与暗蓝→少量火光、尘埃、湿气。每种区域给不同环境线索而不是只是改背景色。
- **遇敌**：看得懂的预备动作→攻击判定→受击反馈→残血紧张音色；不能用不能预判的随机扣血代替难度。
- **开箱**：先听到锁扣、箱盖从原地图位置抬起；短暂流光后出现与已提交宝物完全一致的物件特写。贵重宝物可以多一拍，但不阻止玩家继续操作。
- **撤离**：接近信标时提升音画节奏，成功结算强调“带回了什么”，失败要说明原因和丢失列表。
- **UI**：地图为视觉核心，方向/攻击/互动固定到拇指可达处；宝箱风险选项在选中具体箱子时出现，非所有按钮常驻。横屏保证玩家视觉中央与人物身位可见。

### 3.6 联机/AI 伙伴与安全结算

同伴只根据已探索地图和真实战斗现场行动，可挡刀、打怪、搬运、让出开箱权与救援；模型决策、实做、失败/成功回执分开，不能复制“说了要开箱=已经开箱”。不复用新的影子钱包或平行仓库，使用 RelicEscapeLedger 的原子结算和已存在的跨轮事件记录。

## 四、体验验收原则

同一轮验收至少覆盖：

- 旧档加载与新版重新保存、完全离线行动、退出重启后的物资/动物/房屋/图鉴一致。
- 每个可见实体都能用正常操作触及：小动物确实可结识、稀有箱确实能破封、危险怪物实际出现。
- 玩家选择稳妥/冒险时资源扣减和结算结果不同；重复点击、回退页面、网络恢复不可重复造物。
- 无超出可操作范围的透明按钮、弹出菜单不挡住角色、长按方向不吞输入；低端 Android 的真实帧时间应测量。
- 合作角色说的行为与实体记录一致，结算可追到具体玩家/角色、具体一局/存档。

**完成判定**：源码提交≠JVM回归成功≠APK构建成功≠真机可玩≠玩家觉得好玩。体验测试至少邀请不同偏好的玩家（建造/全收集/冒险）试玩，对“是否知道接下来想做什么”和“是否愿意主动再开一局”记录具体事实再调整。主看板 G-02/G-03 是唯一可勾验收处。
