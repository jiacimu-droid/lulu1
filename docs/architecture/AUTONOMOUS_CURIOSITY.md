# 自主好奇与生活闭环（2026-10）

本次实现不增加监控服务、不添加强制活跃配额、不改变已经保存的角色人格。
入口仍为 `ProactivePerceptionRuntime` 的后台/在线感知；权限、真实状态与最终执行仍交给 `ToolRouter` / `CompanionActionRuntime`。

## 决策闭环

1. 从角色人格、已形成的兴趣、真实阅读/世界/聊天经历中发现可能感兴趣的未知问题。
2. `AutonomousAffordanceContext` 只把目前**真实可执行的**阅读 ID、群 ID、场景活动 ID 和地点 ID 翻译为选择机会，不是必须执行的任务清单。
3. 模型自行选择行动、独处、或留下暂未行动的主观疑问。对于「没有用户新消息」而形式化选择 silent 的情况，只有模型**自己**同时提供明确动机和参数合法的私生活候选，`AutonomousDecisionRecovery` 才将其交给原执行器再次验证；真实想休息时不改变选择。
4. `CharacterCuriosityRuntime` 以证据 ID 区分尚未实践的疑问、执行成功的探索结果与失败回执。不把一句话当客观经历。
5. 探索主题和失败原因在下一次上线再送给模型；已满足的主题自然退出活跃候选。已有 `CharacterDevelopmentRuntime` 继续独立审查多次真实经历，决定兴趣是否成熟，不让单次好奇变成永久人设。
6. 删除原始时间线证据时撤回相关好奇与探索记录；清空角色经历也清空这些数据。

## 约束与测试

- 不允许探索进度从随意生成的临时 ID 入库；必须找到原始事件。
- 人格不同、喜欢的东西不同，行动不是固定概率表或随机轮换。
- 读书前不能宣称已知后文，公共地点必须真实存在，角色不能伪造到场；失败不等于探索成功。
- `CharacterCuriosityRuntimeTest` 覆盖已知事件引发的未行动问题、失败反馈、去重、删除回滚；
  `AutonomousDecisionRecoveryTest` 覆盖真实独处优先、无人联系的自发小事及防止强制社交；
  `AutonomousAffordanceContextTest` 覆盖真实 ID 绑定与非数字角色的能力边界。

后续可从真实用机体验观察：是否有更多出于**角色本人愿望**的探索、同一兴趣能否持续推进、失败后会不会换办法、是否避免无意义发圈和骚扰，而非只看动作执行数量。
