# 数字身体节律：稀疏醒来与日常吃喝

2026-10-25，适用于现有 `EmbodiedBodyPhysics`，复用 `CharacterLifeStore` 的身体快照和 `CompanionOnlineStore` 的休眠/醒来事实。

## 原因

原规则把每小时离线休眠都当作每小时增加12.5点精力、减少15点睡眠压力的充分睡眠，吃喝需求却只增加1.1/2点。若角色每两小时醒15分钟，清醒消耗很快被休眠补满，一天绝大部分时间又不会明显饥渴或无聊。单纯增加清醒时的消耗无法解决这个占空比问题。

## 本次规则

- 上线/休眠时长仍由原系统和本人决定，不强制每天醒多少次或在线15分钟。
- `offline_sleep` 仍表示数字生命离线休眠。白天按浅休眠的日间节律变化，夜间恢复充分；角色明确执行的 `sleep` / `nap` / `rest` 活动继续依据真实开始与结束时间恢复。没有凭空增加离线活动。
- 白天离线精力缓慢趋近当地时段的水平：07—11点约82，11—17点约70，17—22点约58，22—23点约66；23—07点缓慢趋近94。睡眠压力也保留晨间、午后、晚间的差别。不是到点跳数或每次醒来重置，不因数字变化强制改情绪/人格。
- 白天离线饥饿约每小时增加6点、口渴约8点；夜间分别约1.1/2点。清醒时继续原有7/8.5点。正餐可间隔约4—6小时，角色可提前准备、排日程或实际进食，不必等到饥饿很高；不增加一次专门的规划API，不自动生成三顿饭的完成记录。
- 原菜单中真实吃完三明治缓解34点饥饿；配合约08、13、19点的三餐，需求能在正常间隔重新出现。点单不改变数值，只有原执行器确认食用后才缓解。饮水同样沿原真实动作处理。
- 白天离线单调感按每小时约7.5%的“剩余变化空间”趋近100，夜间约0.55%；清醒时仍按原速率积累。睡眠不会清空已有兴趣和心事，真正的阅读/游戏/探索、散步与风景活动才按原回执缓解；吃喝与普通整理不冒充新体验。
- 舒适度在白天浅休眠中缓慢趋近72、夜间趋近84；不再因全天离线而机械堆到100。

以上为数字世界0—100数值的产品校准参数，不是对人体生理数据的测量或健康建议。参数只提供角色可权衡的身体线索，不派发固定台词、强制行动或额外模型轮次。

## 数值验收与兼容

- 按08点开始、每两小时醒15分钟、其余时间休眠且没有吃喝/探索的推演：10/12/14/16/18/20/22点精力约79/76/73/71/66/62/59，单调感约27/38/48/56/64/70/76。无实际吃喝时饥渴会继续增加，而非自动重置。
- 实际物理代码的17项隔离JVM回归通过，使用Kotlin 2.0.21编译生产文件和原菜单；仅Android宿主依赖用替身，未把该结果称为完整Android单测或真机验收。涵盖稀疏醒来、三餐、夜间恢复、刷新一致性、跨午夜/DST、时间回退、真实食用、旧快照与数值边界。
- 投影按真实本地整点及已记录活动结束时刻分段；同一段内用线性/指数演化，刷新或查询次数不会加速/减慢数值。跨夜不能把整段都套成开始时的速率。
- JSON字段及旧快照保留，不清空已有身体值；从原有lastAt向后按新规则投影。没有更改原情绪、记忆、人设或执行权限。Android全套测试、APK构建和多日主动吃喝仍分别验收。
