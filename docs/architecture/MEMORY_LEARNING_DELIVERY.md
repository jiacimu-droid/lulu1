# 记忆、主动学习与阅读：四轮开发

用户确认：2026-10-12。只有实际代码、执行回执和验证结果可以作为完成依据。

## 统一目标

真实经历 → 有效偏好与情境记忆 → 主观感受／疑问 → 选择与表达／学习 → 真实结果 → 修订 → 后续应用。

重要稳定事实持续注入；普通经历按情境召回。喜欢一种互动不意味着每轮强制执行；明确的条件约定在角色自愿选择该互动时生效。原始时间线是派生记录的权威来源。

## 第1轮：重要偏好与表达约定

- `CharacterRelationshipPreferences` 直接投影仍存在的用户原话，不等定期总结，不增设模型调用或持久化影子库。保留明确长期相处要求、完整条件和指定表达形式；普通生活琐事仍由原始时间线及普通记忆管理。
- 常用称呼与拒绝称呼分开。混合纠正、跨私聊／电话／见面、更晚的改口、来源编辑／删除／备份恢复会重新计算；群聊中不明确面向全员的要求不会自动改写所有成员关系。
- 已有 Core／置顶记忆继续使用现有持久化；在精简表达模式也加载核心事实。真实相处偏好进入普通角色网关、群聊成员上下文及实时语音核心；独立内容生成与跨世界人格任务不继承私人关系约定。
- 显式长期条件的短字面表达有窄范围输出检查，例如「选择某种互动时附带指定拟声」。不自动制造互动、不改引用和否定／将来愿望。称呼检查只处理明确呼语，不把讨论词语改掉；群内没有明确回复对象时依赖本人上下文，不擅自改称呼其他成员。
- 普通聊天发送前、手机端电话合成前和见面正文／音轨投递前检查。需要检查的手机端电话等待最终文本，以免流式片段先说出错误再事后改字幕。第三方托管实时 Agent 已生成的音频不能在手机端靠改字幕补救，该路径依靠同步的角色上下文，仍需真机验证。
- 资料页复用现有称呼与社交资料，提供拒绝称呼、持续相处约定的查看；不把短期心情搬入稳定人格页。

确定性即时投影只处理明确表述；更复杂的语义要求继续由已有即时记忆模型判别并保存 Core。它不是任意自然语言都能确定性编译成规则的系统。通用语义条件不硬编码为动作，不假装输出检查可以保证所有第三方模型永不违反偏好。

## 第2轮：召回与行为衔接（待实现）

关键词／语义／人物事件联合检索；关联前因后果；结合当前情境与候选行动获取适用记忆；明确记录候选、实际注入、预算舍弃和失败原因。重要偏好不占普通召回名额，普通琐事能保留与找回。

## 第3轮：自主学习（待实现）

复用好奇心、学习台账、工具执行和原始时间线。自主疑问／真实不足／准备与兴趣 → 真实搜索、网页或内部材料 → 来源与暂定理解 → 练习及应用 → 真实反馈 → 复习与修订。学习目标、暂停、失败重试、预算和重启恢复一起交付；执行成功不等于用户满意，材料接触不等于技能掌握。

## 第4轮：阅读与整体整合（待实现）

具体片段与反应、当下情绪、可选理解、疑问和自愿分享；允许无感与不写读后感，阅读进度不依赖交作文。接通后续心声、愿望、行动、学习与记忆，并完成跨场景、删除、恢复及回归验证。
