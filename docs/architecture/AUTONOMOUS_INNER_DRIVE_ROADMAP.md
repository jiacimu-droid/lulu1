# 自主联想与持续意愿：分阶段开发路线

本文件描述计划和验收边界，不能凭文档声称 APK 已验证。遵循 AGENTS.md 和 UNIFIED_CHARACTER_CONTRACT.md；不新增第二个人格/记忆/动机真相。

## 当前批次（阶段 1–3）
1. **记忆分类与自主联想**：基于现有 Core/Stable/Episode、Fact/Emotion/Timeline、主人偏好/习惯、角色兴趣、未了念头与真实时间，在已有后台模型决策中提供可验证的跨话题联想线索。不将旧情绪当此刻、不将猜想冒充用户事实。
2. **念头与持续意愿贯通**：保持 appraisal.privateIdeas → innerLife.thoughts → innerLife.motives 的清晰选择边界；沿用 motiveId 更新/暂停/放下；承诺仍由 CommitmentTaskStore 管。模型决定升格，不由关键词自动建待办。
3. **真实行动与反馈回流**：从已有执行回执、LearningLedger 和 VerifiedMethod 召回可修订的实际经验；失败、用户不喜欢或来源删除不能被描述为成功。静默和不打扰同样可选。

## 后续（阶段 4–8）
4. **情境触发与唤醒调度**：统一时间、生活活动、近期对话、未完成日程和目标复查的触发优先级；避免沉默空转和重复 API。测量真实成本与后台存活率后调整预算。
5. **意愿冲突与跨天延续**：多个 motive 竞争时保留其各自状态；增加可观察的继续/搁置/释放原因，不对一项没进展的愿望反复刷新 reviewAfter；重启、删除与纠正回归。
6. **自我生活与长链行动**：把读书、联网学习、真实数字世界活动、个人日程和休眠后的再次醒来接成可中断/恢复的多步体验；多工具独立幂等回执，失败不虚构经历。
7. **探索与关系成长**：从真实偏好及好奇生成自主探索机会，比较所学方法在不同情境中的效果；多次证据再内化为稳态习惯，不强制问主人“我该怎么办”。
8. **可见验收与长期运行**：通过“凌晨四点”“披萨”“尝试哄人失败再换方法”“主人拒绝”“一周没新消息”等回放、成本统计和手机连续运行验证；只保留原始事实及完整撤回路径，不因上下文限制删除长年历史。

## 本批必须核查
- 不发额外模型请求；不改权限、消息发送或工具执行器。
- 无用户新消息仍能从自己的历史与时间获得联想素材；空材料允许静默。
- 未经真实回执不算完成行动；主人正面反馈不从执行成功自动推定。
- 单角色证据隔离；旧存档兼容；失效来源不得再次召回。
- Kotlin JVM 测试、Android 构建、CI 与真机属于不同验收层级，分别报告。
