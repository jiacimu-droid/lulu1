# 自主联想与持续意愿：开发路线与实际边界

遵循 AGENTS.md 与 UNIFIED_CHARACTER_CONTRACT.md。以下“接入”仅代表代码已提交，不能代替 APK、真机和长时体验验证。

## 已接入：第 1～3 阶段
1. **记忆分类与自主联想**：已有 Core/Stable/Episode、Fact/Emotion/Timeline、成长分类与真实时间的只读取材。
2. **念头与持续意愿贯通**：privateIdeas、thoughts、motives 仍是原 Store 原规则，主观念头不自动执行。
3. **行动反馈**：学习证据、已验证相处方法、实际执行回执进入已有召回。

## 已接入：第 4～7 阶段
4. **情境触发与唤醒调度**：保留原来的统一决策锁与 WorkManager 调度。motives 到期复盘必须成功完成模型决策后才消费原计划指纹，失败保留重试权；应用重启时恢复未来日程工作，不补做可能已执行的旧动作。
5. **意愿冲突与跨天延续**：额外读取同一 motives 里的等待反馈、未来复查、已暂停与实际行动结果；角色可自由选择继续或放下，程序不按 priority 排队，不新建目标中心。
6. **自主生活与长链行动**：本人日程可引用一个真实 active motiveId，并在 WorkManager 里保留未来醒来机会；到点不是自动执行，动作成功后凭原 ToolRouter 回执关闭日程；旧日程格式无 motiveId 仍正常读取。
7. **自主探索与关系成长**：原好奇心中未解的问题、已执行学习尝试、用户之后的明确反馈与反证进入自主联想，复用真实原始时间线；不为取材新增第二次模型调用。

## 第 8 阶段：主人亲自验收

请主人在新 APK 里检查：深夜关心但不误判、跨天仍能想起披萨、已有愿望是否主动安排日程、方法失败后会否换办法、暂停意愿会否阻断旧计划、费用与手机后台运行是否合乎预期。测试通过前不称为已实现稳定长期拟人表现。
