# 露露机｜小红书、活人感与表达一致性复查（2026-10-14）

> 本文记录已经落实的代码边界及尚未在真机证实的行为。**提交成功不等于端到端验证通过。**

## 总体原则

1. 笔记属于**外部作者**；即使角色阅读后记住和产生个人观点，也不得把博主经历写成自己的亲历。
2. 模型计划不等于动作。工具执行器、实际网页和原始时间线共同决定“已阅读/已发圈/已联系用户”是否为事实。
3. 人格一致性来自持久偏好、称呼、关系经历、可追溯行动与情绪变化，而不是每次复制相同口头禅。
4. 分享欲、好奇心与独处都属于角色自己的选择；阅读完成不强迫私聊或发圈。

## 小红书路径与降级

```text
用户在小红书分享
  -> Android ACTION_SEND
  -> 选择真实私聊对象
  -> 编码为 XHS_NOTE 卡片（外部分享仅验证链接/标题）
  -> 聊天上下文提取：标题+链接+已确认的正文/识图内容（若有）
  -> 角色自主选择 read_xiaohongshu(args.url)
  -> XhsSharedLinkResolver 检验域名、路径、详情 ID、官方短链跳转
  -> XhsReadingEngine.cardForSharedLink
  -> 优先复用 Activity 已附着的同一登录 WebView
     -> 若页面不可用且有合法 token + 显式启用只读 MCP 才可降级
  -> 真实笔记的正文、已加载评论和实际送达的图片
  -> 视觉模型（非必然可用）-> 来源证据 -> 角色可独立形成想法
  -> 后续由自主决策选择：继续查阅/发朋友圈/私聊/写日记/不行动
```

角色自主找新材料的路径仍是 `read_xiaohongshu(args.keyword)`，首页为关键词空串；**不可将搜到的其他笔记冒充用户指定笔记**。指定笔记没有合法详情令牌时，只有已登录且附着的 WebView 能尝试读取；不能凭短链声称已经读过图片。

## 已实现改动

- 新增 `data/XhsSharedLink.kt`，只接受 HTTPS 官方链接；官方短链的重定向有跳数、域名与超时限制，不携带登录 Cookie。
- `XhsReadingEngine.kt` 新增“按分享链接构建笔记”的入口，保留同一浏览器会话与读取缓存；无详情令牌时禁止错误地让 MCP 冒充成功。
- `LuluExternalMcp.kt` 将“按分享链接读指定笔记”与“搜关键词/看首页”区分，并写入不同 `discoveryMode`。
- `CompanionActionRuntime.kt` 与 `LuluDeviceToolBridge.kt` 明确 `args.url` 和 `args.keyword` 的差别；没有执行证据不能伪称已经检索。
- `ProactiveDecisionPrompt.kt` 为下一轮角色自主决策提供最近三天最多两条**实际验证过**的笔记与个人想法；它是行动线索，不是发消息配额。
- `ConversationNaturalnessGate.kt` 保护链接、时间/数量、未读/已读事实与行动承诺，防止自然化复写改变事实。
- `LuluXhsNativeReaderScreen.kt` 优化图文卡片、阅读标题和正文区；分享中的视觉识别最多等待30秒，结果缺失会明确告知。
- `CompanionPresenceDialog.kt` 将诊断/唤醒交互收敛到“此刻”页，并修复查看消息时切换到历史标签的状态残留。
- 增加 `XhsSharedLinkResolverTest` 与 `ConversationNaturalnessGateTest` 的相关回归场景。

## 尚未声称完成

- **网页搜索出现下半屏白色区域**：第三方 SPA 的真实搜索、滚动与登录状态，需要在已登录的 Android 真机 WebView 里重新验证。
- **官方短链**：代码支持受限重定向解析，但真实短链是否返回可读取的详情令牌要用真实链接测试。
- **识图**：只在实际下载图片并成功收到模型理解时，才产生图像知识；图片未被访问或请求失败不能称为已读。
- **发朋友圈与私人分享**：人格指令不强制行动，仍依赖实际自主决策；需要检查在线周期、执行回执和朋友圈数据库。
- **APK 与真机**：必须以最新提交的 GitHub Actions 完整构建和真机体验为准，不能仅凭已推送判断成功。

## 回归检查清单

1. 从外部小红书分享一条带完整链接的笔记给橘子；卡片有标题，无假封面与假识图。
2. 从内置简洁阅读分享已取得正文的笔记；卡片内容可展开，聊天列表正常预览，角色上下文不含 Base64。
3. 在登录内置网页后，请角色“读我刚分享的这一篇”，确认工具明确传入同一笔记链接，证据的 `discoveryMode=shared_link`，失败不改口成搜索成功。
4. 断网、退出网页与关闭 MCP 降级后重复上述操作；角色明确表示读不到，而不是生成伪造的全文摘要。
5. 阅读过后角色可独立选择吐槽、分享、学习或独处；三种平台来源保持分明，未识别图像不入账。
6. 对“还没看/失败/数字/链接”做语言自然化复写，确认不会反转事实；聊天可以简短、调侃、克制，不强制深情。
7. 在头像弹窗切换“此刻 / 想法与行动 / 心声历史”，确保状态与计划不再混放，点击历史消息能回到正确标签。
