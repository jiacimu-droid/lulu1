# 数字生命与数字世界清单架构对照

日期：2026-10-25。按主人提供的二十项优先级逐项对照当前 `main`。本表描述本批实际取舍；公开能力与模型效果不能等同于已在露露机验收。

## 本批实际改动

1. **同一人物的主观连续性**：保留已有 `causalTransitions`，不新建心理 Store。完整版此前漏接简版使用的私有考虑，且召回先取最后四条再过滤，例行回执会挤掉有效念头。现先筛选真实心理内容、按发生时间排序，再取原有四条工作集，简版和完整版共用。理解、未确定之处与共同语境修正可随原事件延续；所有文字明确是当时主观看法，不是新事实或当前命令。
2. **表达交接不丢失**：原记录遗漏 `expression.subtext`、`commonGroundUpdate`，仅有不确定性或表达变化时还可能提前返回。现在在原事件内保存这些既有字段，不因此强迫新心声、情绪或行动。
3. **联想来源的多样性**：已有 `CharacterAssociativeRecall` 虽分记忆和生活方向，但每个方向总挑同一条最强记忆或最新两条经历。现复用 `CharacterAttentionWorkingSet`，按本人已有感知节奏轮换较旧线索；相关召回仍优先，世界经历保留最新一条，原工作集数量不变。没有新轮询、模型请求、永久历史删除或自动行动。
4. **回忆的陪伴分寸**：统一记忆上下文提供简短的使用指导：按当前对象、话题、新原话和当时/现在的区别，选择自然带出、只影响理解、必要核实或暂不提。完整版在实际生效的 `MemoryWorkingSet` 内按原预算和注入审计交付，简版沿原调用交付；测试检查真实网关发出的请求，不新增记忆审判模型或固定安慰模板。
5. **情绪的时间一致性**：完整版旧情绪余波补上与简版相同的未来时间排除，避免将来记录影响较早场景。

## 二十项取舍

| 优先 | 清单项目 | 本批结论与当前落点 |
|---|---|---|
| 1 | SocioMind | 采用“不同心理层级共同参与后续选择”的思路，落实到原主观记录与跨场景召回。现有身份、情绪、motives、关系已分工；不移植 Python 心理状态机、量表转写及逐项额外模型调用。 |
| 2 | M2-her | 借鉴按多轮语境、人物声音、偏好与世界一致性评估表达；保存原表达潜台词。官方当前为64K纯文字对话接口，不自动替换现有模型、工具协议或输入策略；未使用真实密钥做效果对比。 |
| 3 | Jev / Decisions | 采用“给多个独立方向留判断机会”的思想，先修本机联想输入的固定排序。此批未接新的付费接口；Jev默认每问题32K，不能把既有大上下文原样塞入，也不将概率当主观意愿或完成证据。 |
| 4 | Graphiti / JAM | 原系统已有来源版本、失效撤回、原始证据和相关召回。本批补齐原事件中的语境修正与历史解释。保留唯一时间线，不加图数据库或另一套记忆服务。 |
| 5 | Proactive AI 时间线 | 既有持久日程、唤醒指纹、代际检查和新消息所有权继续负责待执行行动。现有候选文字不自动执行；不另造未来消息队列与调度器。 |
| 6 | AI Town / Generative Agents | 现有 DigitalWorldStore、世界事件、物品状态和 SharedExperienceTimeline 承担世界事实。保留其共享状态原则，不迁入 Convex、网页小镇或重复世界引擎。此批未新增购物系统。 |
| 7 | nanoMuse | 原系统已有 Android 后台服务、持久唤醒和执行恢复；借鉴目标持续性，保留现有执行器。未复制 GPL 源码，不引入中继服务或第二条手机控制线路。 |
| 8 | ProMemAgent | 现有 motives 的 reviewAfter、waitingFor 与原日程承接延后意图；本批不增加持续音视频采集和独立前瞻记忆模型。 |
| 9 | ReasoningBank / Hermes | 原 CharacterLearningLedger 已保存实际尝试、失败与反馈、适用和停止条件。本批不再建立“技能经验库”，也不允许未经证据的自修改覆盖核心人格。 |
| 10 | Reconsider | 采用回忆使用的情境与时机判断，接入统一记忆上下文；由原角色模型自己取舍，不增加一次分类请求或统一关心话术。 |
| 11 | Soul of Waifu | 现有身体、情绪、动机和世界物品状态已覆盖基础分工。只保留状态影响选择的原则，未移植 Windows 控制、激素阈值或 GPL 代码。 |
| 12 | AIRI / DLP3D | 原 Live2D 表情动作总线、语音时间线与通话呈现继续使用；DLP3D为3D身体路线，不适合直接替换小狼Live2D。此批不增加模型资产或3D运行时。 |
| 13 | Qwen Omni Realtime | 可作为未来音视频感知候选；整套语音路线涉及实时协议、声音、权限、上下文和费用，不在本批未经实测替换现有通话。 |
| 14 | ProAgent / ProV-Mem | 原屏幕监督、共享观察与去重/节流继续承接。保留“观察不等于必须说话”的原则，不新增高频视频采样与付费判断循环。 |
| 15 | OASIS | 当前为少量居民及本人朋友圈，不适合搬入大规模社交媒体模拟器。已有居民行动、关系和事件系统继续作为唯一来源。 |
| 16 | Project Sid / PIANO | 当前同一角色已有统一上下文及独立动作回执；不把多模块并行理解变成多个独立人格或并行收费脑区。大型Minecraft社会仿真不迁入手机。 |
| 17 | MiniMax / DeepSeek Flash | 模型仍从既有可配置网关选择。没有同场景的真实成功率、延迟和成本证据，不硬编码供应商、不覆盖用户模型选择。 |
| 18 | Kimi / GPT / Gemini | 同上，保留为用户可选能力；不按通用跑分自动更换陪伴人格。现有按任务预算与输入事实组装继续生效。 |
| 19 | memU / Haiku | 现有记忆与提取连接已存在，不另装记忆后端；本批只补记忆使用指导，未增加默认付费提取轮次。 |
| 20 | Qwen ASR / sherpa / Fish / MiniMax Speech | 现有离线Whisper与在线语音为正式路线。新原生推理库、模型下载与音色路线需要手机延迟、发热、中文名字与许可验证，本批不无依据替换。 |

## 验证边界

回归覆盖：例行回执不能挤掉有效念头；理解与不确定性独立延续；未来和无效时间排除；不同人物隔离与来源撤回；表达潜台词保存；旧记忆/旧经历在原预算内轮换；相关记忆持续可见；无记忆不注入额外记忆使用指导。

实际模型的中文陪伴质量、各类性格的自然联想、Redmi锁屏后台连续运行和多日体验仍需真机验证。APK构建与单测只能证明相应代码路径可编译、已测行为符合契约，不代表所有候选项目或模型已经接入。

打包期间额外修复：后续合入的预约校验在无相对时间佐证时，会把角色独自说出的“明天”当成双方已约定日期。现要求此路径的日期来自用户原话，同时保留用户明确日期、角色只复述钟点的合法情况。原失败用例与新增正向用例合计10项纯Kotlin/JUnit测试已在本地通过；全量Android结果另以发布流水线为准。
