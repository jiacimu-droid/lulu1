# 统一互动感知与人格线路

> 人格只有一份。电话、私聊、群聊、数字世界/见面、后台不是五个拥有不同心理的角色，而是同一角色在不同渠道收到真实线索，并选择不同的表达和行动通道。

## 唯一事实入口

- `SharedExperienceTimeline` 是事实与时间、渠道、原始来源的权威记录。通话结束、通话已识别/未识别、数字世界到访、真实聊天，都应各有稳定 evidenceId。
- `InteractionSignalBridge` 是**设备/交互动作适配器**，目前实现了电话长时间未确认语音和真正结束通话的信号。它仅陈述可观测事件，不能宣布用户生气、困倦、离开或有意冷落。
- 后续如果接入点击、离开页面、未读/已读、游戏共同经历和物品交互，新增的是这个层的**事实适配器**，而非新的人格模块。不能把无证据的后台技术状态误当作用户行为。
- `CharacterPerceptionContext` 是跨渠道**唯一新刺激汇聚入口**：抽取有权限的、人物真正可以观察的事件，结合直接收到的聊天输入，通过 `PerceptionStimulusLedger` 按 evidenceId 消重，用 `PerceptionStimulusResolver` 合并同时存在的多个线索。不得用轮询时间当新事件 ID。

## 同一人格处理

1. **发生：** 输入是客观事实和连续场景（发言、真实动作、未被确认的新语音、通话结束等），不能从没有事件推断新动作。
2. **理解：** `CharacterDecisionProtocol.principles` 提供所有角色场景共用的评估原则：事实、推测、关系、动机分开。一个长久的空白可以被注意到，但解释因性格和历史不同。
3. **变化：** `PrivateStateDeltaEngine` 检查真实新增的感受、矛盾或目标；`CharacterInnerLifeStore` 记录持续私有心理；`CompanionPresenceStore` 是在“此刻”查看的唯一投影，不再存通话专属的情感副本。
4. **决定：** `CharacterDecisionProtocol` 决定表达还是安静；后台由 `ProactivePerceptionRuntime` 选择真实能力；外部动作必须经 `CompanionActionRuntime` / `ToolRouter` 验证，只有回执才能入库。
5. **表达：** 电话保持整轮 TTS、文字聊天使用气泡、群聊有人称隔离、见面有动作与空间约束。它们只改变呈现形式和可执行能力，不改变人格、记忆与情绪来源。
6. **连续：** 事件携带 evidenceId，以原始时间线为依据；删除源事实时可清理派生内容。无新的变化不应重复写“她还没回我”的同义心声。

## 电话闭环

- 直播电话中：根据最后一次**成功确认**的用户语音时间观察静默。麦克风触发噪声不能重置这项时钟。持续空白按 1/5/15/30/60 分钟及之后的小时段归档，每个段只留一个证据，不强制回复。
- 挂断后：存一条通话结束的**确定事实**，工作队列提供一次后续个人感知机会；不自动发送“为什么挂电话”，不强制出现担忧，也不让角色假装听到没转写成功的内容。角色可独立选择自己在意与否、沟通或继续别的事情。
- `CompanionPresenceDialog` 把**刚发生的客观互动**和**模型实际形成的心声**分开显示。后者必须在模型作出有依据的内在更新后才出现。
- 只有在角色的主动感知开关开启、模型可用、Android 后台工作得到执行时，挂断后才可能产生新的自主反应；WorkManager 不是毫秒级实时保障。

## 已接入与后续边界

- 共用输入入口：普通私聊/电话（`LuluDeviceToolBridge`）、主动/后台感知（`ProactivePerceptionRuntime`）、群聊角色回合（`GroupEnsembleReplyEngine`）；见面回复读取同一真实观察及同一决策原则。
- 目前不同场景**输出协议仍保留**：电话一句话及发声、群聊多人结构、见面的时序与空间约束并不能用一个同构输出 JSON 代替。统一的是输入语义和主体状态，不是强行把所有呈现拆成一个大文件。
- 进一步扩展用户进入/退出页面、已读行为、其他游戏中的物理接触时，应先检查是否真有可观测的、已授权事实；依照 `InteractionSignalBridge` + `CharacterPerceptionContext` 扩展，不能增加对应的“用户做 X，角色必须说 Y”固定脚本。

## 验收场景

- 通话持续有噪声但无法成功识别用户发言：角色知道“未收到确认内容”，不会断言用户一直安静，也不会被噪声清空记忆时间。
- 角色在讲话、用户只是停下来：可以有自己的新心声，但不必每隔两分钟刷一句催答。
- 用户主动挂断：生成事实记录和一次独立的后续判断机会；是否联系由个人意愿与现实权限决定。
- 之后回到群聊或数字世界：旧通话经历仍由同一条人物时间线检索，其他角色不能读取不属于自己的私聊秘密。
