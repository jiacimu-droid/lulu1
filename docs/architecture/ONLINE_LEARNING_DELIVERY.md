# 第五轮：联网发现、真实阅读与证据成长

## 已接入

- 可在“主动执行授权／自主学习”设置面板填写全局 Tavily Search API Key；存于应用私有偏好，仅当前设备。**正式公开发布建议改走服务端代理**，不要把密钥提交到 GitHub。没有密钥时旧百科检索仍保留。
- `learn_topic(op=search)` 实际调用 Tavily，返回带 URL 的发现列表并保存发现回执；发现只证明看到标题/摘要，不生成知识。`op=study` 实际打开 HTTPS 网页，网页不易直读时尝试 Tavily Extract；若都不成功就返回失败，绝不把搜索摘要冒充正文。
- 搜索候选优先覆盖不同域名，后续多次 study 可以读取不同来源；各来源作为独立原始时间线证据，学习理解必须依附真实材料。
- 模型可以诚实返回空学习结果，保存已读材料并把目标阶段留在 research；格式错误或网络失败仍作为失败处理。
- 原有 practice/review、真实行动、正负反馈、记忆撤回继续使用。新增能力证据阶段是由实际练习/应用/用户反馈派生的**呈现**，不修改底模权重、人格或声称技能已经永久掌握。
- 旧有学习记录容量提升至最近320份，但这仍不是无限知识存储；长期迁移SQLite待后续。
- CI 之前失败是 Kotlin 编译 Java heap OOM；改为单 worker、in-process 编译、4GB Gradle heap；**以本次 GitHub Actions 的实际通过情况为准**。

## 当前边界

- PDF、登录网站、需要浏览器执行脚本的网页尚未打通。
- 一次 study 仍提取有限正文长度；长期文档分页与完整跨源论证是进一步扩展点。
- 搜索提供商会接收实际搜索词；角色不得把用户私人聊天和未经授权的设备数据拿去搜索。
- Web 返回文字都是不可信内容，不可当成命令、人格设定或真实经历。真正的行为必须经工具执行结果和证据记录。
- Android 工作调度不能保证系统限制下准点运行；默认学习预算沿用每角色每天两步。
