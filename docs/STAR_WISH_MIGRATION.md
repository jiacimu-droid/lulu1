# 心愿馆迁移记录

来源：`jiacimu-droid/lulu` 的 StarWish 数据模型、规则、ViewModel 与页面。

## 当前保留

### 画卷

- 从考研存档读取已经解锁的画卷主题；不另建第二套碎片或解锁库存。
- 角色单人／与主人互动两套提示词。
- 每个主题可编辑并保存自定义提示词。
- 使用聊天页当前选中的 API 配置和模型存档调用 `/images/generations`。
- 支持 `b64_json` 和图片 URL 两种返回格式。
- 生成图片保存到应用私有目录，图库持久化展示并可删除。

### 小剧场

- 迁入旧仓库 16 个内置剧场种子与完整核心设定。
- 每个剧场独立保存剧情指南、章节历史和主人对下一章的影响。
- 章节连续生成，最多 20 章。
- 每次成功写入章节只从同一份考研库存精确扣除 1 张小剧场券。
- 模型失败、券不足或章节未写入时不扣券。

## 已移除功能

- 心愿馆旧“视频柜”已经退役，不再提供视频导入、锁定、解锁或播放区域。
- 考研奖励系统不再存在“视频解锁卡”。旧存档中的视频解锁卡、已解锁视频字段与心愿馆 `videos` 数据会在升级迁移时清理。

## 数据存储

- 心愿馆自身数据保存在 `lulu_star_wish` SharedPreferences。
- 图片文件保存在应用私有目录 `starwish/images`。
- 画卷主题解锁和当前角色继续以 `PostgraduateExamStore` 的 `StudyState` 为唯一来源。

## 仍需验收

- 真机验证不同中转站对 `/images/generations`、模型名和返回格式的兼容性。
- 真机验证大图文件、图库滚动、文件删除和应用重启后的恢复。
- 剧场长章节需要继续验证模型上下文上限和 20 章连续性。
- 当前小剧场券精确扣减通过兼容桥调用考研存档的原子更新函数；后续拆分大型考研 Store 时应改成正式公开库存接口，行为不得改变。

在以上真机项目通过前，本模块状态为 **功能迁入完成，真机验收待完成**，不标记为全局迁移完成。
