# 露露机 · 社区许愿与自愿赞赏

入口：**设置 → 社区与支持 → 许愿 / 打赏作者**。

## 许愿如何收到

- 客户端仅存放用户自己填写的本机草稿，**不会偷偷向作者上传角色、聊天或 API 密钥**。
- 点击「前往提交愿望」，使用 Android 浏览器打开预填标题和正文的
  [GitHub Issues 新建页](https://github.com/jiacimu-droid/lulu1/issues/new)。
- 提交者必须登录 GitHub，并主动点击 **Submit new issue**。**只有这一步完成，作者才能在仓库 Issues 看到新的一条愿望**。
- 提交者可在 [Issues 列表](https://github.com/jiacimu-droid/lulu1/issues) 查看公开记录。作者自行分类、回复或关闭；不会从 App 假报已提交。
- 提交是公开的，UI 提示不要包含密钥、姓名、联系方式和个人聊天记录。
- 不需要新建服务器、收费接口或为每位用户创建数据库账号。

## 备用邮箱

维护者已授权把 **1187725424@qq.com** 作为公开反馈邮箱。
客户端显示「改用邮件发送」，通过设备邮件 App 调起草稿；
邮件是否真正送达仍由邮件客户端和服务商决定。修改地址可更新
`app/src/main/java/com/jiacimu/lulu/LuluCommunitySupportScreen.kt` 的
`LuluCommunitySupportConfig.FEEDBACK_EMAIL`。

请勿填入私人主邮箱或任何邮箱密码；收件地址会公开包含在 APK 中。

## 自愿赞赏

维护者明确提供了支付宝个人收款码并同意公开。已从上传图片核对 QR 内容，
使用同一 HTTPS 收款地址生成带完整留白区的 **41 × 41** 二维码，
在「打赏作者」页面离线显示，避免网络图片加载和截图昵称展示。
同设备用户也可点击「打开支付宝付款页」打开该二维码对应的收款地址。

二维码矩阵位于 `LuluAlipayDonationQr.kt`，收款 URL 由
`LuluCommunitySupportConfig.DONATION_URL` 引用同一来源；
不得擅自更换收款人、使用用户可编辑地址或伪造二维码。
支付在支付宝完成，露露机**不采集支付凭证、不代扣款、不绑定模型权益**。
支付宝付款界面可能依法显示收款人的部分实名信息，这不是 App 内裁去昵称就能消除的。

不要把用户本机填写的地址作为其他用户的默认收款人；面向公众发布的收款地址只能由维护者在发版配置中指定。

## 验收

- 设置搜索“许愿”、“打赏”可进入对应页面，后退正常。
- 草稿在离开页面/应用后可恢复；提交按钮仅在标题和正文非空时可按。
- 未登录 GitHub、不点击最终 Submit，都不会有远端记录；只能显示“前往提交”，不可显示“已提交成功”。
- QR 原图与重新生成的二维码均可被独立扫码为同一个支付宝 HTTPS 收款地址；Android 浏览器/支付宝的最终付款与收款人显示仍需真机核对。
- 覆盖 360dp、412dp、深色/浅色、放大字体、小屏键盘与离线状态。
