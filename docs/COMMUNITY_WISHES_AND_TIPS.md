# 露露机 · 邮箱许愿与自愿赞赏

入口：**设置 → 社区与支持 → 许愿 / 打赏作者**。

## 许愿如何收到

- 许愿页可填写标题、想法类型与详细建议；草稿仅保存在用户本机，不会擅自上传角色、人设、聊天内容或 API 密钥。
- 点击「用邮箱发送愿望」后，Android 使用 `ACTION_SENDTO` + `mailto:` 打开用户设备上的邮件应用，预填收件人、标题和正文。
- 作者反馈邮箱：**1187725424@qq.com**。用户**无需 GitHub App、GitHub 账号、仓库访问权**，仓库设为私有也不影响邮箱反馈。
- **打开邮件草稿不等于已发送。** 用户须在邮件应用中检查并手动点击发送，实际投递/送达取决于邮件客户端和服务商；App 不会显示虚假的“提交成功”。
- 没安装或没配置邮件应用时，界面提示用户配置邮箱，或使用「复制愿望」把文字发给作者；页面显示真实收件地址供手动使用。
- 不再使用 GitHub Issues 来收集社区愿望，也不提供公开愿望列表。用户只需填写自己的建议，不会泄露给其他用户。
- 不需要增加服务端、在 APK 中嵌入邮箱密码或让用户登录作者的任何账号。

维护者邮箱在 `app/src/main/java/com/jiacimu/lulu/LuluCommunitySupportScreen.kt` 的 `LuluCommunitySupportConfig.FEEDBACK_EMAIL` 配置。这个地址会出现在 APK 中，应作为公开反馈邮箱使用。

## 自愿赞赏

维护者明确提供了支付宝个人收款码并同意公开。已从上传图片核对 QR 内容，
使用同一 HTTPS 收款地址生成带完整留白区的 **41 × 41** 二维码，
在「打赏作者」页面离线显示，避免网络图片加载和截图昵称展示。
同设备用户也可点击「打开支付宝付款页」打开该二维码对应的收款地址。

二维码矩阵位于 `LuluAlipayDonationQr.kt`，收款 URL 由
`LuluCommunitySupportConfig.DONATION_URL` 引用同一来源；
不得擅自更换收款人、使用用户可编辑地址或伪造二维码。
支付在支付宝完成，露露机**不采集支付凭证、不代扣款、不绑定模型权益**。
支付宝付款界面可能依法显示收款人的部分实名信息，这不是 App 内裁去昵称就能消除的。

不要把用户本机填写的地址作为其他用户的默认收款人；面向公众发布的收款地址只能由维护者在发版配置中指定。

## 验收

- 设置搜索“许愿”、“打赏”可进入对应页面，后退正常。
- 草稿在离开页面/应用后可恢复；仅标题、正文非空且作者邮箱有效时允许打开邮件草稿。
- 只进入邮件编辑器而没有点击“发送”时，本机草稿仍在，不能报告“已提交”。
- 无邮件应用时展示明确错误提示，复制愿望、手动发邮件仍可用。
- 测试邮件标题、中文正文、换行、特殊符号的 URI 编码与收件邮箱保持一致。
- QR 原图与重新生成的二维码均可被独立扫码为同一个支付宝 HTTPS 收款地址；Android 浏览器/支付宝的最终付款与收款人显示仍需真机核对。
- 覆盖 360dp、412dp、深色/浅色、放大字体、小屏键盘与离线状态。
