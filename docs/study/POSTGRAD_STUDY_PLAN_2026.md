## 4. 月计划

### 8月21—31日：重置顺序

核心目标：**刑法退出听课线；法理背诵真正启动；宪法先于民法进场。**

- 8月22—23日：法理从第2章继续第一轮背诵，第1章做一次闭卷回忆。
- 8月24日起：宪法成为唯一新课主线，按“课程 → 最低框架 → 精选章节题”推进。
- 刑法只安排第一轮系统背诵，不再重复课程和框架。
- 英语只在专业课注意力明显下降时作为 20—40 分钟切换项。
- 月末验收：法理第一轮明显推进；宪法至少完成前半并有题目闭环；刑法背诵已启动。

### 9月：两门小科清零，民法接管新课

核心目标：**上旬完成宪法、法制史新课；中旬以后民法成为唯一大体量新课。**

- 宪法：课程、框架、精选题清零 → 第一轮背诵。
- 法制史：宪法结束后立即接入，完成课程、框架、精选题 → 第一轮背诵。
- 法理：完成第一轮后每周闭卷回忆，遗忘章节优先回炉。
- 刑法：完成第一轮系统背诵并串联全书目录。
- 民法：9月中旬正式进场，此后新课时间主要给民法。
- 每周至少一次客观错题复盘 + 一次主观题列点。
- 政治不启动；英语维持机动。

### 10月1—18日：清零所有常规新课

核心目标：**最迟10月18日前不再欠常规新课。**

- 10月上旬优先完成民法全部常规课程、随课框架和精选章节题。
- 民法课程结束后立即推进第一轮系统背诵，不等待“更合适的时间”。
- 法理、刑法、宪法、法制史进入二轮闭卷回忆。
- 专业基础/专业综合开始分科真题、错题二刷和主观题列点。
- 10月15日起政治正式启动。
- 英语恢复最低保温，但仍不占专业课核心时段。

### 10月19—31日：从“学知识”切到“会考试”

- 民法第一轮背诵收口。
- 五科二轮按薄弱度推进。
- 专业基础、专业综合都进入分科真题与限时输出。
- 建立三类漏洞清单：**不会 / 容易混 / 会但写不出来**。
- 主观题开始关注法言法语、层次和答题纸空间。

### 11月：三轮 + 真题 + 整卷

- 五科第三轮闭卷输出。
- 专业基础与专业综合轮换真题/高质量套卷。
- 由分科训练逐步过渡到整卷与答题纸。
- 做题与复盘时间原则上至少 1:1。
- 英语恢复计时真题、翻译/阅读复盘和作文素材。
- 政治稳定推进选择题、错题与主观题框架。

### 12月：模拟、压缩、保温

- 专业基础、专业综合、英语、政治进入考场节奏训练。
- 五科专业课仍保留每日/隔日框架抽背，不因做套卷停止记忆维护。
- 只补模拟反复暴露的高价值漏洞。
- 停止建立新笔记体系，逐步压缩成考前可快速翻阅的材料。
- 考试周主动降量，睡眠和稳定输出优先。

## 5. 周计划的分配原则

APP 中已按日期写入具体周任务，这里只保留总规则：

1. 每周先放 **30—32h 核心任务**，不把 35h 常态容量排满。
2. P0 顺序固定为：**真实新课尾量 → 当前轮背诵 → 必要题目/真题输出**。
3. 只有 4h/天时，先删英语，再压可替代题量；不删 P0，不跳章。
4. 达到 6h/天时，多出的时间先给专业课长章、遗忘章节和真实尾量，不自动新增固定任务。
5. 每周末根据番茄统计和实际完成章节滚动；“日期到了”不等于“任务完成”。
