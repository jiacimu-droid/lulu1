# 考研学习习惯与容量基线

> 最近更新：2026-08-21
>
> 这份文档只记录长期用于排计划的学习习惯、容量和优先级。具体月份、周任务和进度见 `POSTGRAD_STUDY_PLAN_2026.md`。

## 1. 当前有效基线

- 专业课优先级最高。当前阶段时间不足时，先保证专业课的新课、背诵和题目闭环。
- 听课习惯：通常使用 **4 倍速**。计划不能直接拿“视频原始分钟 ÷ 4”当完整工作量；暂停、理解、回看、框架、章节题都要算进真实有效学习时长，并用番茄统计持续校准。
- 每日有效学习容量：
  - **4 小时**：低状态保底，不因为当天状态差就把任务判定为失败。
  - **5 小时**：当前常态规划基线。
  - **6 小时**：状态较好时的冲刺容量，用来加速 P0 主线、补遗忘点或提前消化真实尾量。
- 高强度内容并不适合硬撑超长连续块。默认把一次高强度学习控制在约 **25—50 分钟**，注意力开始散就短休息，再继续累计当天有效时长。
- 吃饭、消化、午休本来就会占掉明显时间，而且饭后更容易困；计划不把这些生活时间伪装成可学习容量，也不把高强度背诵硬塞在饭后立即开始。
- 框架图属于“帮助定位结构”的轻量产物，通常控制在 **约10—20分钟/章**；不追求为了好看而抄书式重画。
- 休息日由本人根据当周状态自行选择，**不固定星期几**。即使一周没有完整休息日，也要保留周容量缓冲，不把每天都排到理论上限。
- 不要求固定钟点表。以“周任务池 + 当天自主选择 P0 块”为主；未完成的高优先级任务滚动进入下一周，不用熬夜惩罚式补课。

## 2. 当前学科优先级

### P0：必须先完成

1. 尚未完成的专业课常规新课及真实尾量。
2. 当前轮次的专业课系统背诵与闭卷回忆。
3. 与已学章节对应的最低题目闭环：精选章节题、错题、主观题列点。
4. 进入真题阶段后的专业基础/专业综合真题与复盘。

### P1：重要，但可以围绕 P0 调节数量

- 已学章节的客观题二刷。
- 主观题完整书写、法言法语和答题纸训练。
- 低频薄弱点专项补课。

### P2：当前机动项

- **英语**：现阶段可以放轻。专业课学累、注意力下降时，用 20—40 分钟单词、阅读、翻译或真题片段换脑；不设置为了打卡而存在的每日硬任务。
- **政治**：2026-10-15 前不占固定时段；从 2026-10-15 起正式启动，并逐步增加选择题、基础课、错题和主观题框架。

## 3. 每周容量算法

按 7 天估算：

| 状态 | 理论容量 | 建议排入周计划 | 用法 |
| --- | ---: | ---: | --- |
| 低状态 | 28h | 24—27h | 只守住 P0；先砍英语和可压缩题量 |
| 常态 | 35h | 30—32h | 当前默认排法；留 3—5h 缓冲 |
| 冲刺 | 42h | 34—37h | 富余优先给专业课真实尾量、背诵和遗忘回炉 |

如果连续两周实际有效时长明显低于/高于 5h/天，应按真实番茄统计重新缩放后续周计划，而不是继续沿用旧估算。

## 4. 时长估算怎么滚动校准

旧计划里的“每章平均分钟”只能作为历史参考，不能在教材版本、章节长度或学习阶段已经变化后继续硬套。现在统一使用三层估算：

1. **听课预算**：按真实播放速度估一个起点，但把暂停、回看和理解时间算进去。
2. **闭环预算**：额外加入框架、章节题、错题和当轮背诵时间；听完视频绝不等于这一章已经完成。
3. **实测修正**：每周末用 APP 的有效学习分钟和真实完成章节，计算“这一周每个工作包实际花了多少小时”，再修正下一周，不让一个旧平均数控制到考前。

因此，计划里的 12—14h、19—21h 等都是**工作包预算区间**；真正的约束是“不跳章、不漏闭环、总周容量不超载”。

## 5. 专业课“完整学完”的定义

考试范围内的一本专业课不能因为“课听完了”就从计划消失。完整闭环至少包含：

1. 常规课程/知识理解。
2. 章节框架或全书结构定位。
3. 章节题/客观题与错题记录。
4. 第一轮系统背诵。
5. 第二轮闭卷回忆与遗忘点回炉。
6. 客观题错题二刷。
7. 主观题审题、列点、法言法语输出。
8. 分科真题。
9. 专业基础/专业综合限时整卷与答题纸训练。
10. 考前高频框架、反复错点和熟题保温。

周计划可以改变每一步的题量和深度，但**不能让任何考试科目永久缺少某一条线**。

## 6. 滚动调整规则

- 一周结束先看真实完成量，再排下一周；不为保持日期漂亮而跳章。
- 如果新课出现长章节：顺延章节数量，保留真实学习闭环。
- 如果只有 4h/天：优先级依次是“新课真实尾量/当前背诵 → 必要题目 → 其他复习 → 英语”。
- 如果达到 6h/天：先加速专业课，不自动把多出的时间填成新的固定任务。
- 某科闭卷失败率高时，下周按遗忘率追加时间，不平均主义地给五科各分相同分钟。
- 真题阶段做题与复盘必须同时出现；只做卷不复盘不算完成。
