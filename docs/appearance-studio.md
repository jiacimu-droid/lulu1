# Lulu 美化工坊（Android / Compose）

## 已接入

- 桌面独立「美化」入口（第 15 个桌面快捷方式，旧布局空位自动补入）。
- 内置九套方案：原生留白、奶油布艺手账、怪盗漫画（P5 灵感）、云笺宋韵、午夜蔷薇（哥特）、漫画留声、雨后青苔、银雾未来、星眠日记。
- 分 App 存储主题选择；聊天入口和聊天详情共用 Chat 作用域，通话与番茄钟小窗独立。
- 另存新方案允许调整点缀色和圆角；内置方案只读，不会在另存时被覆盖。
- 仅允许删除未被任何 App 使用的自定义方案，防止悬空引用。
- 主题色、Material3 字体与矢量底纹通过 Compose 作用域注入；桌面、聊天气泡、设置、健康、通用 UI 已初步接入。
- Android 私有 SharedPreferences 保存，应用重启重新读取。

## 架构入口

- data/LuluAppearance.kt：主题模型、内置方案、各 App 作用域、纯函数选择与存档逻辑。
- data/LuluAppearanceStore.kt：JSON 本地持久化与 StateFlow；升级时不覆盖既有个人数据。
- design/LuluAppearanceTheme.kt：Material3 色彩/字体作用域及无外部依赖的 Canvas 矢量纹理。
- LuluAppearanceScreen.kt：美化工坊、预览、切换、另存。
- LuluMigrationRootAppV2.kt：路由隔离与通话/番茄钟小窗独立作用域。

## 验收

1. 桌面旧布局自动显示「美化」，拖动其他 App 不应改变已存布局。
2. 桌面应用「奶油布艺手账」，聊天应用「怪盗漫画」；来回切换确认各自独立。
3. 打开聊天详情：应跟随「聊天」方案，不会意外回退到桌面主题。
4. 将「午夜蔷薇」另存副本，换色和圆角；原方案仍存在。
5. 杀死进程重开：桌面和各 App 方案保持；最近使用顺序保持。
6. 不能删除任意仍被 App 使用的自定义主题；切换后可删除。
7. 检查字体、背景、聊天气泡、健康日历、设置卡片在深色和浅色方案的可读性。

## 后续视觉工作

此版本的主题纹理是轻量矢量绘制，不含高质量背景插画、布料贴图或字体文件。下一步再把素材资源作为可选主题层接入，同时继续拆除各页面残余的硬编码颜色和布局，不应将这轮视作全面完工。
