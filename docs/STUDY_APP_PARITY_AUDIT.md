# 考研 App 功能对等审计

基线：`jiacimu-droid/lulu` 的 `StudyPage.kt`、`StudyVM.kt`、`StudyStore.kt`、`StudyRules.kt`。
目标：新 UI 可以重做，但旧业务功能、数据、奖励、设置和历史能力不得丢失。

## 审计结论

当前 `lulu1` 的考研 App **不是完整迁移**。它已完成今日任务、番茄钟、基础抽卡、票券显示、成就和学习时长，但仍遗漏旧版多个完整分区和业务链路。

## 已迁入

- 今日任务新增、完成和番茄钟数量
- 今日学习分钟数、词汇量和连续学习数据
- 25/45/60 分钟番茄钟
- 语音陪伴开关状态
- 单抽券、十连券、学习币、夸夸值和碎片显示
- 单抽与十连抽
- 紫色碎片 6%、抖音 5%、番外小剧场 1%
- 基础成就进度与领取
- 学习数据对角色开放的仓库接口
- 奖励时间仅作参考、角色最终判断的规则说明

## 旧版存在但当前遗漏

### 陪伴与成长

- 学习陪伴角色选择
- 每日签到
- 角色等级和等级奖励
- 睡眠习惯奖励卡
- 最近学习事件记录
- 不活跃惩罚

### 今日与计划

- 主模型生成今日时间表
- 生成计划的 Token/模型使用统计
- 今日计划时间块
- 明日待办
- 学习 Tips
- 周计划
- 月计划
- 系统计划与手动任务同步
- 删除系统任务后不自动重新加入的规则
- 当前周恢复顺序和阶段性考研节点

### 奖励链路

- 普通完成奖励领取
- 神秘盒子
- Super Moment 选择奖励
- 今日安全抽/紫票抽取
- 保底追踪
- 普通、稀有、史诗等完整稀有度体系
- 普通碎片套装
- 万能普通碎片及自动选择最佳补齐目标
- 视频解锁与心愿馆联动

### 收藏

- 已解锁画卷
- 小剧场收藏
- 娱乐奖励兑换
- 收藏内容播放和视频展示

### 商店

- 每日商店
- 手动刷新商店
- 商品库存与售罄
- 使用夸夸值购买
- 首次进入购买与刷新状态

### 说明和其他

- 完整玩法说明页
- 抽卡动画与不同稀有度展示
- 弹窗、Snackbar 和失败提示
- 数据持久化与日期切换同步

## 后续验收规则

1. 上述所有遗漏项迁入前，考研 App 状态保持“部分迁移”。
2. 新页面不得恢复旧 UI，但必须保持功能对等。
3. 与模型、角色、心愿馆、Token 统计相关的跨模块链路必须一并验收。
4. 新增功能不能替代旧功能。
