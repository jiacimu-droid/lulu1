# 角色连续生活：本批交付

## 问题与实际改动

此前虽有心声、阅读、游戏、动态和数字世界执行器，却主要按单轮选择行动。主观愿望与执行结果没有单独持久化关联；聊天反馈也没有直接唤起增量成长批次。

本批沿用同一角色、时间线、承诺、工具与世界状态，没有另做人格：

- 角色设置增加五项可选行为设定：在意与底线、关心方式、分歧与受挫、自己的兴趣、语言与情绪。留空继续使用原人设；填写后通过统一角色上下文进入聊天、通话与后台决策。
- 新增持久化的持续动机：目标、原因、形成时间、近期真实执行回执。聊天与后台都可形成动机；下一轮不会因生成新愿望而覆盖旧愿望。
- 后台仍使用现有调度、安静时段和授权。模型结合愿望与实际结果选择继续、换办法、等待、安静或放下；本批没有新增更频繁的轮询。
- 共同工具路由把手机、应用、世界、云任务的实际返回接回角色生活状态。回执按执行 ID 去重，失败保留失败，文字示爱不计成任务完成。云任务提交成功只证明提交，不证明产物完成。
- 主观愿望与真实承诺任务分开：不由模型给持续愿望勾选“已经完成”。放下愿望只是选择变化；需要核实的承诺仍使用原 CommitmentTaskStore。
- 用户可在角色设置查看正在在意的事及最近结果，并结束它。旧轮次的放下请求必须匹配当前动机 ID；用户结束的相同愿望不能立即重新开启。
- 普通聊天记录中的用户反馈可触发现有每小时限频的后台成长反思，沿用原事件版本、反例、人设和重复经历校验。成长批次不阻塞当前回复；不保证每次都形成新习惯。
- 原心情和心声继续存入 CompanionPresenceStore。加强混合情绪、不同意见和具体关心的表达规则；它们是角色主观描写，不宣称真实意识或模型内部推理。

## 手机使用

覆盖安装新 APK，不卸载。打开角色设置，按需要填写五项行为设定。比如“关心时会记得我说过的小事，做得到就行动；不把每句话都变成示爱”。不同角色应填写各自的表达方式，不需要全都热情黏人。

需要角色离开聊天后继续阅读、玩游戏或发动态时，打开原有主动感知并选择安静时段；应用必须拥有系统允许的后台调度条件。手机设备工具仍按原授权执行。缺权限会留下失败，角色不能凭愿望获得权限。

“正在在意的事”只会在角色实际提出持续动机后出现，未形成时没有预置演示记录。阅读要有已导入正文，世界行动要有可用世界和真实物品。没有资源时不会用虚构经历代替。

## 数据兼容

新增 `lulu_character_life` SharedPreferences，不重建旧数据库、不清空旧记忆。应用与后台都加载此存储；原完整备份包括 SharedPreferences。清空角色记录会去掉动机和回执，保留用户填写的性格设定。工具来源事件被更正或删除后，其对应生活回执立即移除。

## 边界

当前采用一个主要持续动机和最近 12 条实际动作回执；回执是期间真实动作，不自动证明每个动作都推进该愿望。还没有多目标长期规划器、自动心理分析或独立情绪数值模型。真实经历的自动分享继续复用原时间线检索与发布执行器，没有新增必发朋友圈或每日示爱规则。

性格差异、细腻程度与长期习惯效果需要真实模型和多日使用验证；编译和规则测试不能证明“已经像真人”。本批不修改语音供应商链路，也不宣称在线语音验收完成。

## 验证

新增 Robolectric 测试覆盖：动机不被下一轮覆盖、按角色隔离、写入持久化配置、重复回执、失败不改成功、安静不记行动、用户结束后不重开、旧 ID 不清掉新动机、放下不等于完成、更正回执清理、清空记录保留性格设定。

最终 APK、测试与构建结果在本次交付说明中分别报告。安卓设备和真实模型体验由手机实际使用确认。
