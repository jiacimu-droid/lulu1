# Lulu UI 设计系统

## 已选方向：方案 B · 暖纸极简

本文件是 `lulu1` 的正式视觉基准。桌面及后续聊天、记忆、辞海、世界书、性能监测、阅读、心愿馆、考研、游戏和设置页面均应遵守本规范。

## 1. 设计关键词

- 暖白纸感
- 简约、安静、清楚
- 浅麦黄色强调
- 低饱和蓝灰线条
- 轻边框、低阴影
- 少渐变、少装饰
- 充分留白
- 信息层级优先于装饰

## 2. 基础色板

建议先以以下颜色作为设计 token，真机预览后允许小幅调整：

- `background`: `#FBF8F1` — 主页面暖白底色
- `surface`: `#FFFDF8` — 卡片和弹层
- `surfaceMuted`: `#F7F2E8` — 次级区域
- `primary`: `#EFCF7A` — 麦黄色主强调
- `primarySoft`: `#F8E9B9` — 浅黄色背景
- `accentBlue`: `#7C899A` — 蓝灰辅助色
- `textPrimary`: `#393732` — 主文字，不使用纯黑
- `textSecondary`: `#77736C` — 次级说明
- `border`: `#E9E0D2` — 轻边框
- `error`: `#C9746C`
- `success`: `#809A79`

## 3. 阴影与边框

- 卡片优先使用浅边框区分层级，阴影只作为辅助。
- 禁止大面积强阴影、发光边缘和高饱和玻璃拟态。
- 普通卡片圆角建议 `18–22dp`。
- 小按钮、图标容器圆角建议 `12–16dp`。
- 主按钮可使用胶囊形圆角。

## 4. 字体层级

- 主问候：大号、较有呼吸感，但不得占据半屏。
- 页面标题：清楚、稳重，不额外增加冗长副标题。
- 正文：优先保证阅读性。
- 次要说明：蓝灰或暖灰，不使用过浅文字。
- 中文正文默认使用系统字体，避免依赖额外字体文件。

## 5. 桌面结构

### 顶部区域

保留：

- 日期或时间段问候
- 简短陪伴文案
- 当前角色小头像

要求：

- 不制作笨重的大标题栏。
- 问候文字应动态变化，但不影响主要入口。
- 头像点击可进入当前角色资料或角色切换。

### 最近聊天卡

桌面的主要交互入口，包含：

- 最近聊天角色头像
- 角色名称
- 最近消息摘要
- 最近聊天时间
- `继续聊天` 主按钮

点击整张卡或主按钮均应直接进入该角色的聊天页面。

无最近会话时显示轻量空状态，并引导进入聊天 App 选择角色。

### App 网格

桌面保留以下入口：

1. 聊天
2. 记忆
3. 辞海
4. 世界书
5. 性能监测
6. 阅读
7. 心愿馆
8. 考研
9. 游戏
10. 设置

桌面不再单独出现：

- 日志：合并进性能监测
- 角色：合并进聊天 App
- 我的：合并进聊天 App

图标要求：

- 统一线条粗细和视觉尺寸。
- 以蓝灰为主，麦黄色只做小面积强调。
- 不使用十种互不相关的高饱和颜色。
- 图标文本必须可读，点击区域不得小于 Android 推荐触控尺寸。

## 6. 页面通用组件

后续各 App 应共享：

- 页面背景
- 顶部导航栏
- 返回按钮
- 卡片
- 主/次按钮
- 输入框
- 开关
- 标签页
- 弹窗
- 空状态
- 错误状态
- 加载状态

禁止每个页面自行定义一套完全不同的颜色和圆角。

## 7. 聊天页面方向

聊天页面采用熟悉的即时通讯信息结构，但不复制 QQ、微信或旧项目的具体视觉资产：

- 顶部：返回、头像、名称、状态、通话和更多
- 中部：左右消息气泡、时间分隔、连续消息合并
- 底部：语音、输入框、附件、更多、发送
- 键盘与输入区之间不得出现无意义空白
- 不保留自动生成对话建议的入口与链路
- 编辑、删除、收藏、分支等操作放入长按菜单

## 8. 动效原则

- 动效短、轻、可打断。
- 页面切换不使用夸张缩放。
- 按钮只提供轻微按压反馈。
- 列表加载使用柔和占位，不使用持续闪烁。
- 尊重系统“减少动态效果”设置。

## 9. 无障碍与真机适配

- 关键文字与背景必须保持足够对比度。
- 触控目标不小于约 `48dp`。
- 支持系统字体放大，不能因字号变化严重截断。
- 支持窄屏和长屏，桌面网格不能依赖固定截图尺寸。
- 状态栏、导航栏和键盘区域必须使用安全区域。

## 10. 验收方式

每个阶段先提供无需打包的预览，再正式接入代码：

1. 静态效果图：确认颜色和信息结构。
2. 可交互 HTML/Compose Preview：确认真实布局、滚动和点击状态。
3. 合入 Android 页面。
4. GitHub Actions 构建 APK。
5. 真机检查后微调 token，而不是逐页面临时改色。

## 11. 不应照搬的内容

- 旧项目桌面或聊天页面的具体视觉布局
- QQ、微信的图标和像素级布局
- 未确认来源的插画、角色素材或字体
- 只存在于概念图、但无法在真机稳定实现的装饰

概念图用于确认风格，不作为可直接复制的最终资产。
