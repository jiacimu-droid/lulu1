# 人格、当下与自主生活

用户设定的人格与价值是稳定约束，由 CharacterRuntime 统一装配；当前心情与心声由 CompanionPresenceStore 保存；持续愿望由 CharacterLifeStore 保存；基于反复真实证据形成的兴趣和习惯由 CharacterDevelopmentStore 管理。聊天、电话和自主感知读取同一套装配。人格页将当下心声、经历形成的兴趣、固定设定和持续愿望放在一个页面。

持续愿望可以保持、根据新反馈更新，或有理由地放下。更新必须引用当前动机 ID 并附原因，保留原起点和执行回执；不把改变愿望当作完成行动，也不按固定次数变换性格。读完真实正文后，角色可以喜欢、无感、失望、想继续或想停；感想、当下心声与可选动机更新会在阅读成功提交之后保存。

一次唤醒在原有五分钟范围内每约一分钟提供后续自主选择机会。角色可以继续、换事做、保持安静，不固定轮换动作。正在通话或生成回复时让出机会；自主动作不会延长自己的生活脉冲窗口。Android 后台调度及网络可能使实际执行延后；没有成功执行器回执就不产生完成事实。进程重启时仍在线的角色恢复剩余窗口。

上传正文按每角色游标续读；小剧场同一作品按章节顺序开放下一章，不因新章排在列表前面而跳章。最近真正读过的作品及完整读后感进入后续选择上下文，先前愿望参与决定，而不是强制追更。

电话页不展示模型候选文本。进入发声队列的当前一句显示正式字幕，播放完成后转入持久化通话记录，字幕行使用渐入及移动动画；通话状态与计时各保留一个位置。旧存档与角色锁定设定保持兼容。
