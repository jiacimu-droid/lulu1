## 最新业务闭环

### 记忆与召回

- 聊天每次成功生成角色回复后检查记忆阈值。
- 最近 N 条消息不会参与提取。
- 只有完整批次达到阈值才调用模型。
- 模型失败或 JSON 无效时不推进处理检查点。
- 成功批次可连续处理，不停在 20、40 等边界。
- 允许主动回忆的记忆、辞海和世界书会进入真实模型 Prompt。

### 约定与监督

- 在用户提出监督、提醒、责任或长期承诺，并完成一轮角色回复后触发。
- 一句话中的多项要求必须拆成独立条目。
- 支持承诺、责任、提醒、长期监督四种底层类型。
- 已处理用户消息使用持久化检查点防止重复写入。
- 模型或格式失败不写检查点，不会永久跳过。

### Token 与性能

- 每次模型调用记录来源、模型、接口输入/输出、缓存 Token、实际计入值和 Prompt 来源拆分。
- 接口不返回 usage 时，控制台明确显示“未返回”，并使用估算值而不是全部显示为零。
- 报错记录来源、标题、地址和失败前耗时。
- 学习、聊天、通话累计时长通过系统事实向所有角色提供。
