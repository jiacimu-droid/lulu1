# Apocalypse visual assets

These images are bundled locally in the Android app; the app does not hotlink them at runtime.

- `apocalypse_city_night.jpg` — **Industrial city at night**, author Paolo Neo. Public Domain. Source: https://commons.wikimedia.org/wiki/File:Industrial_city_at_night.jpg
- `apocalypse_factory_interior.jpg` — **Abandoned factory interior (31260792602)**, author Fairy Duff. Public Domain Mark. Source: https://commons.wikimedia.org/wiki/File:Abandoned_factory_interior_(31260792602).jpg
- `apocalypse_dark_tunnel.jpg` — **Dark Empty Tunnel**, author TomIsNotResponding. CC0 1.0 Universal. Source: https://commons.wikimedia.org/wiki/File:Dark_Empty_Tunnel.jpg

The UI applies blue/black overlays at render time; the source JPEG files are retained as downloaded.
