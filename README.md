# 露露机 Lulu

> 一个真正属于用户自己的 Android AI 陪伴应用。

## 项目状态

`lulu1` 是露露机的新项目，也是从零开始的独立 Android 重构。当前计划内的代码迁移主体已经完成，正在进行最终 APK 构建和真机验收。

- 迁移范围与取舍：[`docs/MIGRATION_PLAN.md`](docs/MIGRATION_PLAN.md)
- 当前真实验收状态：[`docs/MIGRATION_STATUS.md`](docs/MIGRATION_STATUS.md)
- 功能对等核查：[`docs/FUNCTION_PARITY.md`](docs/FUNCTION_PARITY.md)
- 代码来源与归属：[`docs/PROVENANCE.md`](docs/PROVENANCE.md)
- 暖纸极简设计系统：[`docs/DESIGN_SYSTEM.md`](docs/DESIGN_SYSTEM.md)

这个仓库**不会通过修改说明文件，把旧项目的代码包装成原创项目**。旧仓库 `jiacimu-droid/lulu` 建立在 OrangeChat / RikkaHub 等既有项目基础上；新仓库会把它们仅作为功能需求和使用体验的参考，不直接整仓复制旧骨架。

新项目中的每个模块都需要满足以下至少一种情况：

1. 由本项目重新设计并独立实现；
2. 明确来自第三方开源项目，并完整遵守其许可证和署名要求；
3. 暂时无法确认来源时，不迁入正式代码。

## 露露机想做什么

露露机不是普通聊天客户端，而是一个“生活在手机里的 AI 伴侣”。核心目标包括：

- 长期记忆、关系连续性和角色一致性；
- 手机桌面式界面与独立功能入口；
- 语音输入、通话状态和主动联系；
- 学习月计划、周任务池、番茄钟、抽卡激励和考研工具；
- 责任与承诺自动拆分、主动提醒和生活监督；
- 可持续维护的 Android 架构和稳定 APK 发布流程。

## 当前已经接通

- 暖纸极简桌面与十个 App 入口；
- 多角色聊天、消息树、收藏、分支、附件和语音识别输入；
- 角色人设、世界书、辞海和连续记忆进入真实模型上下文；
- 记忆固定批次提取、失败重试、阈值设置和调试信息；
- 承诺、责任、提醒和长期监督从聊天自动拆分写入辞海；
- 性能报错、缓存、Token 控制台和角色可读累计时长；
- 心愿馆、考研、抽卡奖励、小游戏记录与逐步回放；
- Lulu1 完整本地备份，以及旧露露 ZIP 的聊天、记忆和模型配置迁移；
- 固定开发签名、原有自动构建发布工作流和代码索引工作流。

## 重构原则

- **不整仓复制**：不把旧仓库换名后继续使用。
- **功能逐块搬迁**：先写清需求和数据结构，再独立实现。
- **来源可追踪**：每个迁入模块都记录来源、作者和处理方式。
- **数据优先**：页面可打开但无法保存，不视为迁移完成。
- **保持可运行**：每轮代码提交都通过现有发布工作流构建 APK。
- **少而稳定的自动化**：只保留正式构建、发布与索引流程，不创建一次性工作流。
