# 露露机 Lulu

> 一个真正属于用户自己的 Android AI 陪伴应用。

`lulu1` 是露露机当前正式开发仓库。产品目标不是普通聊天客户端，而是一个生活在手机里的长期 AI 伴侣：拥有角色一致性、连续记忆、主动联系、通话、学习陪伴、健康数据和手机桌面式交互。

## 当前产品方向

- 白色与中性灰为主的手机桌面视觉；
- 私聊与群聊两种正式聊天类型；
- 角色人设、世界书、辞海与长期记忆进入真实模型上下文；
- 主动消息、责任、承诺、提醒和长期监督；
- 文本聊天、语音输入、电话与群聊互动；
- 考研计划、番茄钟、抽卡奖励和学习记录；
- 健康日历、经期提醒与手环健康数据展示；
- 心愿馆、朋友圈、游戏、阅读和性能监测；
- 本地备份、旧数据兼容、固定签名与自动 APK 发布。

## 开发边界

- 只修改现有 `main` 分支；
- 不新建分支，不创建额外或一次性工作流；
- 页面修改必须同时检查真实数据、持久化、失败状态和旧数据兼容；
- 不根据旧文档擅自恢复主人已经删除的功能；
- 代码检查与自动构建不能代替真机验收；
- 不直接复制来源不明或许可证不明确的第三方代码和资源。

完整规则见 [`AGENTS.md`](AGENTS.md)。
